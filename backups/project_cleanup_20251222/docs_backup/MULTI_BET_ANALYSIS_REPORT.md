## 4. 推奨パターン詳細

### 4.1 パターンH: 1-2軸3点傾斜配分（最推奨）

**買い目ルール**:
```
1着: 予測1位（固定）
2着: 予測2位（固定）
3着: 予測3位, 4位, 5位

配分:
- 1-2-3: 200円（主力）
- 1-2-4: 100円（補助）
- 1-2-5: 100円（補助）

合計: 400円/レース
```

**実績**:
- 年間収支: +68,030円
- ROI: 127.3%
- 的中率: 9.0%（59/652）
- 最大ドローダウン: 53,050円

**現行戦略からの改善**:
- 収支: +30,980円（+83.6%）
- 的中率: +5.5ポイント

### 4.2 パターンB: 1-2軸3点均等配分（ROI最大）

**買い目ルール**:
```
1着: 予測1位（固定）
2着: 予測2位（固定）
3着: 予測3位, 4位, 5位

配分:
- 1-2-3: 100円
- 1-2-4: 100円
- 1-2-5: 100円

合計: 300円/レース
```

**実績**:
- 年間収支: +55,680円
- ROI: 130.3%（最高）
- 的中率: 9.0%（59/652）
- 最大ドローダウン: 35,770円（低リスク）

**特徴**:
- 投資額が現行と同じ300円
- ROI最大で効率的
- ドローダウンが小さく安定

### 4.3 パターンK: 総合買い（安全重視）

**買い目ルール**:
```
- 1-2-3: 150円（主力）
- 1-2-4: 100円（補助）
- 2-1-3: 50円（裏目カバー）

合計: 300円/レース
```

**実績**:
- 年間収支: +39,995円
- ROI: 122.8%
- 的中率: 8.4%
- 最大ドローダウン: 33,075円（最小）

**特徴**:
- ドローダウンが最小で精神的に安定
- 1-2着の入れ替わりもカバー

## 8. トリガミリスク分析

複数点買いの場合、的中してもトリガミ（払戻<投資）になるリスクがある。

| パターン | 1レース投資 | 的中時平均払戻 | 収益倍率 | トリガミ閾値 |
|---------|------------|--------------|---------|-------------|
| H: 傾斜配分 | 382円 | 5,375円 | 14.07倍 | 3.8倍以下 |
| L: 重点買い | 391円 | 6,757円 | 17.28倍 | 3.9倍以下 |
| B: 均等配分 | 282円 | 4,061円 | 14.40倍 | 2.8倍以下 |

**結論**: 戦略Bの対象オッズレンジ（20-50倍）では、トリガミリスクは極めて低い

### 10.1 最終推奨

**パターンH: 1-2軸3点傾斜配分（200/100/100円）**
