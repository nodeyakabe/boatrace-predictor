## 2. 現状の問題点（優先度順）

### 2.1 Critical（致命的）

#### 問題1: 直前情報の効果がほぼゼロ

**現状の数値**（BEFOREINFO_UTILIZATION_REPORT.md より）:

| 指標 | advance（事前） | before（直前） | 差分 |
|------|-----------------|----------------|------|
| 1着的中率 | 50.77% | 50.82% | **+0.06pt** |
| 2着的中率 | 23.51% | 23.54% | **+0.02pt** |
| 3着的中率 | 20.19% | 20.17% | **-0.02pt** |
| 3連単完全一致率 | 5.52% | 5.55% | **+0.04pt** |

**根本原因**:
1. **事前予測と直前予測の相関が高すぎる**
   - 良い選手は展示タイムも良い傾向
   - 直前情報が「予想を覆す」情報として機能していない
2. **重み付けの問題**
   - `FINAL_SCORE = PRE_SCORE * 0.6 + BEFORE_SCORE * 0.4` だが、両者の相関が高いため差別化できない
3. **スコアリング方式の問題**
   - 展示タイムを相対順位（1位25点、2位18点...）で評価しているため、絶対的な差がつきにくい

**影響**:
- 40%もの重みをかけている直前情報が実質的に無効
- 115点満点のスコアリングシステムが機能していない
- 直前情報の取得・処理コストが無駄になっている

---

#### 問題2: 過去予想一括作成時のデータ汚染の可能性

**ユーザーからの懸念**（LATEST_STRATEGY_SUMMARY.md より）:
> 「直前情報の活用状況　これに関しては過去の予想を一括で作成した場合に直前情報を加味した予想になってしまうので同じ予想が保存されている可能性がとても高い」

**分析結果**:
- BEFOREINFO_UTILIZATION_REPORT.mdの検証では、advance → before の改善効果はわずか+0.04pt
- これは「直前情報が効いていない」証拠でもあるが、「データが同一になっている」証拠でもある可能性
- **両方の可能性を排除できない状況**

**影響**:
- バックテスト結果の信頼性に疑問
- 直前情報の本当の効果が測定できていない可能性

### 2.2 High（重要）

#### 問題3: サンプル数が少ない条件への依存

**現状**（ALL_CONDITIONS_MATRIX_2025.md より）:

| 条件 | 購入数 | 的中数 | ROI | 収支 | 統計的信頼性 |
|------|--------|--------|-----|------|--------------|
| D x A1 x 40-50倍 | 53 | **1** | 405.8% | +48,630円 | **低** |
| D x A1 x 200-300倍 | 50 | 1 | 461.6% | +54,240円 | **低** |
| C x A1 x 120-150倍 | 60 | 2 | 440.0% | +61,200円 | **低** |

**問題点**:
- 高ROI条件の多くは的中数1-2件
- 2026年に的中しない可能性が十分にある
- 統計的揺らぎによりROIが大きく変動するリスク

**数学的根拠**:
- 的中1件の条件で真のROIを推定すると、95%信頼区間は非常に広い
- 例: 53件中1件的中 → 真の的中率は0.1%〜10%の範囲に収まる可能性

#### 問題4: 信頼度A/Bが実質的に使用できない

**現状**（CONFIDENCE_AB_VERIFICATION_REPORT.md より）:

| 信頼度 | 年間レース数 | 的中数 | 的中率 | ROI | 判定 |
|--------|--------------|--------|--------|-----|------|
| A | 43 | 4 | 9.30% | 122.6% | **サンプル不足** |
| B | 1,419 | 129 | 9.09% | 77.4% | **赤字** |

**問題点**:
- **信頼度A**: 年間わずか43レース（月3.6レース）しか該当しない
- **信頼度B**: サンプル数は十分だが、主要条件（A1級、低オッズ帯）で全て赤字
- 「高信頼度 = 高収益」という期待が成り立っていない

**根本原因**:
- 信頼度の定義が「予測の確実性」ではなく「データの充実度」に偏っている可能性
- 信頼度A/Bの条件（高スコア差）が収益性と相関していない

#### 問題5: 2着・3着予測精度の低さ

**現状**（残タスク一覧.md より）:

| 指標 | 現状 | 目標（保守的） | 目標（楽観的） |
|------|------|----------------|----------------|
| 1着的中率 | 50.82% | 54% | 57% |
| 2着的中率 | 23.54% | 30% | 35% |
| 3着的中率 | 20.17% | 27% | 32% |

**問題点**:
- 2着的中率23.54%は、理論上の期待値（約20%：残り5艇からの選択）とほぼ同等
- 3着的中率20.17%も、理論上の期待値（約25%：残り4艇からの選択）を下回る
- **2着・3着の予測に付加価値がほとんどない**

**影響**:
- 3連単的中率 = 1着的中率 x 2着的中率 x 3着的中率 が低く抑えられている
- 現状の4.32%から6%に上げるには、2着・3着予測の改善が必須

## 3. 改善提案（優先度別）

### 3.1 最優先（即座に実施）

#### 改善1: 差分ベースの直前情報スコアリング導入

**現状の問題**:
- 直前情報スコアが事前スコアと高相関で、順位変動が起きない

**改善案**:
```python
# 現状: 絶対値ベース
BEFORE_SCORE = 展示タイム順位(25点) + ST評価(25点) + ...

# 改善: 差分ベース
BEFORE_SCORE = (事前予測順位との乖離) x 重み
# 例: 事前予測4位の選手が展示タイム1位 → 大きく加点
# 例: 事前予測1位の選手が展示タイム1位 → 小さく加点
```

**実装内容**:
1. `src/prediction/beforeinfo_scorer.py` に差分スコア計算を追加
2. 「事前予測との乖離」を評価する新メソッド追加
3. 閾値ベースのボーナス導入（例: ST 0.10秒以下 + 展示タイム1位 → +10点）

**期待効果**:
| 指標 | 現状 | 期待 | 改善幅 |
|------|------|------|--------|
| 3連単的中率 | 4.32% | 4.8-5.0% | +0.5-0.7pt |
| 1着的中率 | 50.82% | 52% | +1.2pt |

**実装コスト**: 低（1-2日）
**成功確率**: 70%
**根拠**: BEFOREINFO_UTILIZATION_REPORT.md の提案「差分ベースのスコアリング」

#### 改善6: advance/before予測データの検証・再生成

**目的**: データ汚染の有無を確認し、必要に応じて再生成

**実施内容**:
1. DBの`race_predictions`テーブルでadvanceとbeforeの差異を確認
2. 同一レースでadvance/before予測が異なるか統計的に検証
3. 問題があれば、2025年全期間の予測を再生成

**検証コード例**:
```sql
SELECT
    COUNT(*) as total,
    SUM(CASE WHEN p1.predicted_1st = p2.predicted_1st
             AND p1.predicted_2nd = p2.predicted_2nd
             AND p1.predicted_3rd = p2.predicted_3rd
        THEN 1 ELSE 0 END) as identical
FROM race_predictions p1
JOIN race_predictions p2 ON p1.race_id = p2.race_id
WHERE p1.prediction_type = 'advance'
  AND p2.prediction_type = 'before';
```

**期待効果**:
- データ品質の確認
- 直前情報の真の効果測定が可能に

**実装コスト**: 中（1-2日 検証 + 3-4時間 再生成）
