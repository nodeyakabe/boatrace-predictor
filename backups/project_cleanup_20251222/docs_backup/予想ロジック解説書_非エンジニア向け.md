## 1. システム概要

### このシステムは何？

**競艇の3連単を予想して、儲かるレースだけを自動で見つけるシステム**です。

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  レース情報  │ ──→ │  予想エンジン │ ──→ │  購入判断   │ ──→ │   買い目    │
│  を収集     │     │  で順位予測  │     │  で選別     │     │   を提示    │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
```

### 3つの基本ステップ

| ステップ | 内容 | 例 |
|---------|------|-----|
| **① 情報収集** | 選手成績、モーター、展示タイムなど | A1級、モーター2連率40%、展示6.78秒 |
| **② 順位予測** | 各艇に点数をつけて順位を決定 | 1号艇120点 → 1着、3号艇95点 → 2着... |
| **③ 購入判断** | 条件に合うレースだけを買い目として提示 | 信頼度C、オッズ35倍 → 購入！ |

### なぜ儲かる？

- **全レースを買わない** → 条件に合うレースだけ（1日2〜3レース程度）
- **的中率は低くてOK** → 約4%の的中率でも、30〜50倍のオッズで回収
- **データに基づく** → 感覚ではなく、過去何万レースの統計から判断

## 2. 予想の仕組み

### 全体の流れ

予想は「**5つの層**」を順番に通って、最終的な順位予測が出ます。

```
【第1層】基本スコア
    ↓ 選手の実力・モーター性能・コース有利を点数化
【第2層】拡張スコア
    ↓ 展示タイム・スタートタイミング・直近成績を加味
【第3層】環境補正
    ↓ 風向き・風速・潮の満ち引きで調整
【第4層】直前情報パターン
    ↓ 「このパターンなら勝つ」という法則を適用
【第5層】AI統合
    ↓ 機械学習モデルで最終調整
【出力】1着〜6着の順位予測 + 信頼度（A〜D）
```

### 各層でやっていること

#### 第1層：基本スコア（土台作り）

| 項目 | 評価内容 | 重要度 |
|------|---------|--------|
| **級別** | A1 > A2 > B1 > B2 | ★★★★★ |
| **コース** | 1コースが圧倒的有利（勝率58%） | ★★★★★ |
| **モーター** | 2連対率が高いモーターは強い | ★★★★☆ |
| **選手成績** | 勝率・2連率・3連率 | ★★★★☆ |

#### 第2層：拡張スコア（詳細評価）

| 項目 | 評価内容 | 配点 |
|------|---------|------|
| **展示タイム** | 当日の船の調子を反映 | 8点 |
| **平均ST** | スタートの上手さ | 10点 |
| **直近成績** | 最近の調子 | 8点 |
| **級別スコア** | A1=10点、A2=7点、B1=4点、B2=1点 | 10点 |

**配点の合計**: 約62点満点

#### 第3層：環境補正

| 環境要因 | 影響 |
|---------|------|
| **追い風** | インコースが有利 |
| **向かい風** | アウトコースが有利 |
| **風速5m以上** | 荒れやすい（予想しにくい） |
| **満潮** | インコースが有利 |
| **干潮** | アウトコースが有利 |

#### 第4層：直前情報パターン（法則適用）

「**こういう状態の艇は勝ちやすい**」という法則を適用します。
（詳しくは[第4章](#4-パターンボーナス)で解説）

#### 第5層：AI統合

機械学習モデル（LightGBM）で最終調整：
- **1着確率モデル**: 誰が1着になりそうか
- **2着確率モデル**: 1着が決まったとして、誰が2着か
- **3着確率モデル**: 1着・2着が決まったとして、誰が3着か

この「条件付き確率」で三連単の的中率を上げています。

## 3. スコアリング

### 点数の付け方（Extended Scorer）

各艇に以下の項目で点数をつけ、合計点でランキングします。

```
┌────────────────────────────────────────────────┐
│              スコアリング配点表                 │
├──────────────────┬─────────┬─────────────────┤
│ 項目              │ 配点    │ 説明            │
├──────────────────┼─────────┼─────────────────┤
│ 級別スコア        │ 10点    │ A1=10, A2=7...  │
│ 平均STスコア      │ 10点    │ スタート上手い程高 │
│ 展示タイムスコア  │ 8点     │ 展示で速い程高   │
│ 直近成績スコア    │ 8点     │ 最近勝ってると高  │
│ 進入傾向スコア    │ 5点     │ コース取り上手い  │
│ 選手間相性スコア  │ 5点     │ 過去対戦成績     │
│ モーター特性      │ 5点     │ モーターの癖     │
│ 節間成績          │ 5点     │ 今節の調子      │
│ 前走レベル        │ 5点     │ 前走の相手強さ   │
│ チルト角度        │ 3点     │ -0.5〜+3.0      │
│ 会場別勝率        │ 3点     │ その場での相性   │
├──────────────────┼─────────┼─────────────────┤
│ 合計              │ 約67点  │                │
│ F/Lペナルティ     │ -10点   │ 失格歴あると減点  │
└──────────────────┴─────────┴─────────────────┘
```

### 信頼度ランク

予想結果には「信頼度」がつきます。これは「どれくらい自信があるか」を表します。

| ランク | スコア差 | 意味 | 購入対象 |
|-------|---------|------|----------|
| **A** | 20pt以上 | 超自信あり | ❌ 対象外 |
| **B** | 15〜20pt | かなり自信 | ❌ 対象外 |
| **C** | 10〜15pt | 中程度の自信 | ✅ 購入対象 |
| **D** | 10pt未満 | やや自信低め | ✅ 購入対象 |

**なぜA・Bは買わない？**
- A・Bランクは発生件数が少なく、統計的に信頼できるデータが不足
- C・Dランクの方が長期的な回収率が安定

## 4. パターンボーナス

### パターンボーナスとは？

「**直前情報を見て、勝ちパターンに該当したら加点する**」仕組みです。

**直前情報とは**：
- **PRE順位**: 事前予想での順位（級別・成績などから算出）
- **展示順位**: 展示タイムの速さ順位
- **ST順位**: 平均スタートタイミングの順位

### 1着予測パターン（PRE1位の艇に適用）

| パターン名 | 条件 | ボーナス倍率 | 効果 |
|-----------|------|-------------|------|
| **最強複合** | PRE1位 & ST1位 & 展示1位 | ×1.50 | +50%のスコア加算 |
| **PRE1+ST1** | PRE1位 & ST1位 | ×1.41 | +41%のスコア加算 |
| **三冠パターン** | PRE1位 & 展示1-3位 & ST1-3位 | ×1.33 | +33%のスコア加算 |
| **PRE1+展示1** | PRE1位 & 展示1位 | ×1.29 | +29%のスコア加算 |
| **PRE1+ST上位** | PRE1位 & ST1-3位 | ×1.31 | +31%のスコア加算 |

**具体例**：
```
1号艇: PRE順位1位、ST順位1位、展示順位2位
  → PRE1+ST1パターンに該当
  → スコア 100点 × 1.41 = 141点に加算！
```

### ネガティブパターン（減点パターン）

「**こういう状態の艇は危険**」というパターンでは減点します。

| パターン名 | 条件 | 減点倍率 | 意味 |
|-----------|------|---------|------|
| **ST最下位** | PRE1位なのにST6位 | ×0.53 | -47%減点（危険） |
| **ST下位** | PRE1位なのにST5-6位 | ×0.80 | -20%減点 |
| **両方最下位** | ST5-6位 & 展示5-6位 | ×0.60 | -40%減点 |

**具体例**：
```
1号艇: PRE順位1位だが、ST順位6位（スタート遅い）
  → PRE1_ST6パターンに該当
  → スコア 100点 × 0.53 = 53点に減点！
  → 「人気だけど危ない」と判断
```

### 2着予測パターン

| パターン名 | 条件 | ボーナス倍率 |
|-----------|------|-------------|
| **PRE2+ST上位** | PRE2位 & ST1-2位 | ×1.12 |
| **PRE2三冠** | PRE2位 & 展示1-3位 & ST1-3位 | ×1.08 |
| **PRE2+ST1-3** | PRE2位 & ST1-3位 | ×1.06 |
| **PRE2+展示上位** | PRE2位 & 展示1-3位 | ×1.06 |

### 3着予測パターン

| パターン名 | 条件 | ボーナス倍率 |
|-----------|------|-------------|
| **PRE中位+展示中位** | PRE3-4位 & 展示2-4位 | ×1.03 |
| **PRE3+展示上位** | PRE3位 & 展示1-3位 | ×1.03 |
| **アウト穴狙い** | 4-6枠 & ST1-2位 | ×1.02 |

### 3着以内パターン（超重要）

| パターン名 | 条件 | ボーナス倍率 | 効果 |
|-----------|------|-------------|------|
| **ダブル上位** | ST1-2位 & 展示1-2位 | ×1.35 | +35%（最強パターン） |
| **PRE上位+ST1** | PRE1-3位 & ST1位 | ×1.23 | +23%（強力） |
| **トリプル上位** | PRE1-3位 & ST1-3位 | ×1.13 | +13% |

## 5. 会場の特徴

### 会場ごとの「インの強さ」

競艇は1コース（イン）が有利ですが、**会場によって差**があります。

```
【1コース勝率の全国平均】57.87%

【インが強い会場】平均より+5%以上
  🥇 徳山   +9pt  → 1コースがとても強い
  🥈 大村   +8pt  → 1コースがとても強い
  🥉 下関   +6pt  → 1コースが強い

【インが弱い会場】平均より-5%以上
  ⚠️ 戸田   -12pt → 1コースが弱い（荒れやすい）
  ⚠️ 平和島 -12pt → 1コースが弱い（荒れやすい）
  ⚠️ 江戸川 -9pt  → 1コースが弱い
  ⚠️ 鳴門   -8pt  → 1コースが弱い
```

### コース別の調整ポイント

会場とコースの組み合わせで、スコアを加減算します。

**例：徳山競艇場**

| コース | 調整 | 意味 |
|-------|------|------|
| 1コース | **+9** | 平均よりかなり有利 |
| 2コース | -2 | 平均よりやや不利 |
| 3コース | -3 | 平均より不利 |
| 4コース | -2 | 平均よりやや不利 |
| 5コース | -2 | 平均よりやや不利 |
| 6コース | ±0 | 平均並み |

**例：戸田競艇場**

| コース | 調整 | 意味 |
|-------|------|------|
| 1コース | **-12** | 平均よりかなり不利 |
| 2コース | +3 | 平均より有利 |
| 3コース | +4 | 平均より有利 |
| 4コース | +3 | 平均より有利 |
| 5コース | +1 | 平均よりやや有利 |
| 6コース | +1 | 平均よりやや有利 |

→ **戸田は「荒れる会場」なので、2〜4コースにチャンスあり**

### センター・アウトが強い会場

| 特徴 | 会場 |
|------|------|
| **センター（3,4コース）が強い** | 戸田、平和島、福岡 |
| **アウト（5,6コース）が強い** | 桐生、鳴門 |

## 6. 購入判断

### 購入条件マトリクス（戦略B）

すべてのレースを買うわけではありません。以下の条件を満たすレースだけを購入対象とします。

```
┌─────────────────────────────────────────────────────────────┐
│                    購入条件マトリクス                        │
├──────────┬─────────┬────────────┬─────────┬────────────────┤
│ 信頼度   │ 級別    │ オッズ範囲 │ 賭け金  │ 期待ROI        │
├──────────┼─────────┼────────────┼─────────┼────────────────┤
│ C        │ B1      │ 30〜40倍   │ 300円   │ 158.6%（主力）│
│ C        │ A1      │ 30〜40倍   │ 300円   │ 141.7%        │
│ D        │ B1      │ 40〜50倍   │ 300円   │ 132.0%        │
│ D        │ A1      │ 40〜50倍   │ 300円   │ 405.8%（穴）  │
│ D        │ A2      │ 20〜30倍   │ 300円   │ 173.3%        │
└──────────┴─────────┴────────────┴─────────┴────────────────┘
```

### 購入から除外する条件

| 条件 | 理由 |
|------|------|
| 信頼度A, B | サンプル不足で安定しない |
| 級別B2 | 回収率が低い |
| オッズ10倍未満 | 配当が低すぎる |
| オッズ100倍以上 | 的中率が低すぎる |

### 複数点買い（パターンH）

1点だけでなく、3点買いで的中率を上げます。

```
【パターンH】
  ・1-2-3 → 200円（予測どおり）
  ・1-2-4 → 100円（3着を4位に変更）
  ・1-2-5 → 100円（3着を5位に変更）
  ─────────────────
  合計: 400円/レース
```

**効果**: 3着予測が外れても、4位・5位が入れば的中

### 1日の購入レース数

- **平均2〜3レース/日**
- 年間で約830レース購入
- 年間的中数: 約36回（的中率4.3%）

## ❓ よくある質問

### Q1: 的中率4%で本当に儲かるの？

**A**: はい、儲かります。ポイントは**配当の高さ**です。

```
【計算例】
・1回の購入: 400円（3点買い）
・月の購入: 400円 × 60レース = 24,000円
・月の的中: 3回（的中率5%）
・平均配当: 45倍 × 200円 = 9,000円
・月の回収: 9,000円 × 3回 = 27,000円
・月の収支: 27,000円 - 24,000円 = **+3,000円**
```

### Q2: なぜA・B信頼度は買わないの？

**A**: サンプル数が少なく、統計的に信頼できないからです。

- A信頼度の年間発生数: 約50件
- B信頼度の年間発生数: 約100件
- C・D信頼度の年間発生数: 約750件

→ C・Dの方がデータが多く、安定した回収率を計算できる

### Q3: 会場調整って何？

**A**: 会場ごとの特性に合わせてスコアを調整することです。

例えば徳山は1コースが強いので、1コースにボーナス（+9pt）を加えます。
逆に戸田は1コースが弱いので、ペナルティ（-12pt）を加えます。

これにより、会場の特性を考慮した精度の高い予想ができます。
