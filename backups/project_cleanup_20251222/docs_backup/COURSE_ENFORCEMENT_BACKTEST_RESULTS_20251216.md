## 1. エグゼクティブサマリー

### 1.1 結論

**コース強制化は1着予測精度を向上させるが、ROI・収支を大幅に悪化させる**

| 指標 | 修正前（強制化なし） | 修正後（強制化あり） | 変化 |
|------|---------------------|---------------------|------|
| **ROI** | 167.0% | 116.0% | **-51.0pt** |
| **収支** | +166,860円 | +38,850円 | **-128,010円** |
| **的中率** | 4.34% | 3.58% | -0.75pt |
| 購入数 | 830件 | 809件 | -21件 |
| 的中数 | 36件 | 29件 | -7件 |

### 1.2 判定

- **統計的有意性**: なし（Z統計量 = -0.78、p > 0.05）
- **実務的有意性**: あり（年間約13万円の収支悪化）
- **推奨**: **コース強制化は適用しない**

---

## 2. 背景

### 2.1 予測戦略見直しの動機

- **1着予測精度**: 49.8%（ベースライン55.1%を下回る）
- **問題**: 非1コース予測の精度が低い（24.8%）
- **仮説**: 低精度な非1コース予測を1コースに強制すれば精度が改善する

### 2.2 実施した改善

**コース強制化ロジック**:
- 閾値: スコア差15pt未満
- 対象: 非1コース予測で、1コースとのスコア差が15pt未満のレース
- 効果: 該当レースの1位予測を1コースに強制変更

**精度への影響**:
- 1着予測精度: 49.8% → 55.4%（**+5.6pt**）
- ベースライン比: -5.3pt → +0.2pt（**ベースライン超え達成**）

## 5. 強制化適用レースの詳細分析

### 5.1 基本統計

| 項目 | 値 |
|------|-----|
| 強制化適用レース | 203件 |
| 1コースが実際に1着 | 81件（39.9%） |
| 元の予測コースが1着 | 47件（23.2%） |

### 5.2 3連単的中の変化

| パターン | 件数 | 説明 |
|---------|------|------|
| 強制化後のみ的中 | 3件 | 強制化により的中した |
| 強制化前のみ的中 | 4件 | 強制化により不的中になった |
| 両方的中 | 0件 | 変更がなかった |
| 両方ハズレ | 196件 | どちらも不的中 |

**重要な発見**:
- 強制化により**4件**の的中を失い、**3件**しか獲得できなかった
- 差し引き**-1件**の的中減少

### 5.3 オッズへの影響

コース強制化の主な悪影響:
1. **非1コース予測は高オッズであることが多い**
2. **1コースに強制すると平均オッズが下がる**
3. **的中しても払戻が少ない**

**例**:
- 修正前: `3-2-4` 予測（高オッズ）→ 的中時の払戻大
- 修正後: `1-3-2` 予測（低オッズ）→ 的中時の払戻小

## 6. 原因分析

### 6.1 精度とROIのトレードオフ

| 指標 | 精度への影響 | ROIへの影響 |
|------|------------|------------|
| 1着予測精度 | +5.6pt（改善） | - |
| 3連単的中率 | -0.75pt（悪化） | 悪化 |
| 平均オッズ | - | 低下（悪化） |
| 購入機会 | -21件（減少） | 機会損失 |

### 6.2 なぜ1着精度が上がってもROIが下がるのか

1. **3連単は2着・3着も正確に予測する必要がある**
   - 1コースに強制しても、2着・3着の予測は変わらない
   - 結果、3連単の的中率は改善しない

2. **高オッズ狙いの機会を失う**
   - 非1コース予測は荒れレースを狙う戦略
   - 強制化により、高配当の機会を逃す

3. **購入対象からの除外**
   - 強制化後のオッズが購入条件を満たさなくなるケース
   - 購入機会が21件減少

## 8. 結論と推奨

### 8.1 結論

**コース強制化は採用しない**

- 1着予測精度は改善するが、ROI・収支は大幅に悪化
- 精度改善の指標（+5.6pt）は、実際の収益に直結しない
- ベッティング戦略においては、**ROIが最重要指標**

### 8.2 推奨アクション

1. **config/prediction_strategy.yaml の設定変更**:
   ```yaml
   course_enforcement:
     enabled: false  # 無効化
   ```

2. **現行戦略の維持**:
   - 戦略B（5条件）をそのまま継続
   - 年間ROI 167%、収支+166,860円を維持

3. **今後の改善方向**:
   - 2着・3着予測の精度向上（1着だけでなく）
   - オッズを考慮した期待値ベースの最適化
   - 条件別の細分化（会場別、信頼度別など）

### 8.3 学んだ教訓

1. **精度とROIは別物**
   - 1着予測精度が上がってもROIは上がらない
   - ベッティングでは「どのレースで当てるか」が重要

2. **バックテストの重要性**
   - 理論上の改善が実際の収益に結びつくとは限らない
   - 必ずROIでの検証を行う

3. **高オッズ戦略の価値**
   - 非1コース予測は荒れレース狙いとして機能している
   - 安易に「安全策」に走ると収益機会を失う
