## 3. 中期改善策（1-2ヶ月）

### 3.1 直前情報の活用改善

**現行ロジック**:
```python
FINAL_SCORE = PRE_SCORE * 0.6 + BEFORE_SCORE * 0.4
```

**改善案**:
```python
# 差分ベースのスコアリング
if 事前予測と直前情報で大きな乖離:
    FINAL_SCORE = PRE_SCORE * 0.5 + BEFORE_SCORE * 0.5
else:
    FINAL_SCORE = PRE_SCORE * 0.7 + BEFORE_SCORE * 0.3
```

**具体的な実装**:
1. 事前予測順位と展示タイム順位の乖離度を計算
2. 乖離が大きい場合（例: 4位以上の差）、直前情報の重みを上げる
3. 乖離が小さい場合、事前予測を信頼

### 3.2 2着・3着予測の強化

**現行**:
- 全艇を同一スコアで評価
- 上位3艇を1-2-3位として出力

**改善案**:
- 条件付き確率モデルの導入
- P(2着=B | 1着=A) を計算
- 決まり手別の着順パターンを統計化

**実装**:
1. `hierarchical_predictor.py` の活用度を上げる
2. 決まり手予測モジュールとの連携強化
3. 1着確定後の2着・3着を条件付きで再予測

### 3.3 期待効果

- 2着的中率: +5-10pt
- 3連単的中率: +2-3pt
- ROI: +10-20pt

## 4. 長期改善策（3ヶ月以上）

### 4.1 機械学習モデルの導入

**現状**:
- ルールベースのスコアリング
- 手動で設計した重み付け

**改善案**:
- XGBoost / LightGBM での予測モデル構築
- 特徴量: 選手成績、モーター成績、コース、オッズ、直前情報
- 目的変数: 1着フラグ、2着フラグ、3着フラグ

**実装ステップ**:
1. 学習データの準備（2022-2024年のレース結果）
2. 特徴量エンジニアリング
3. モデル学習と検証
4. 現行ルールベースとのアンサンブル

### 4.2 オッズ解析の導入

**現状**:
- オッズは購入判断にのみ使用
- 予測精度向上には活用されていない

**改善案**:
- オッズから「市場の予測」を抽出
- 自己予測と市場予測の乖離を分析
- 乖離が大きい場合のみ購入（期待値の歪みを狙う）

### 4.3 リアルタイム学習

**現状**:
- モデルは固定（定期的な手動更新）

**改善案**:
- 毎日の結果を学習に反映
- オンライン学習による継続的な改善
