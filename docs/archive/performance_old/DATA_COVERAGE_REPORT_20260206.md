本調査では、2020年～2025年の競艇データの充足状況を6つのテーブル別に分析しました。特に、今回追加された **2021年9-12月** および **2023年1-12月** のデータを重点的に確認しています。

#### 2. データ品質の問題点

1. **race_dateがNullのレース**: 84,384レース（21.6%）
   - これらのレースは年度別集計から除外される可能性あり
   - データクレンジングが必要

2. **2023-12月のデータ異常**: 56,592レース（通常の10倍以上）
   - データ収集時の重複やエラーの可能性
   - 要調査・修正

3. **充足率のばらつき**
   - 2024-2025年は高充足率（97%以上）
   - 2020-2023年は充足率が低い（10-67%程度）

### 3.2 充足率の傾向

#### 高充足率（90%以上）

- **2024-2025年**: 最近のデータは比較的高充足率
  - 出走表・結果: 97-99%
  - 詳細: 30-71%（改善の余地あり）
  - 予測: 33-83%（改善の余地あり）

#### 低充足率（60%未満）

- **2020-2023年**: 過去データの充足率が低い
  - 特にオッズデータが極端に低い（8-33%）
  - 詳細・予測データも不足

### 3.3 データの問題点

#### 1. race_dateがNullのレース（84,384件）

```sql
-- 確認クエリ
SELECT COUNT(*) FROM races WHERE race_date IS NULL;
-- 結果: 84,384レース
```

**影響**:
- 年度別集計から除外される
- バックテスト時に期間フィルタが正常に機能しない
- 予測生成時にエラーの原因になる可能性

**対策**:
- venue_code + race_number + race_timeから日付を推測
- 元データソースから再取得
- 復元不可能な場合は削除を検討

#### 2. 2023-12月のデータ異常（56,592レース）

通常月の約10倍以上のレース数が記録されており、データ重複の可能性が高い。

**調査方法**:
```sql
-- 重複確認
SELECT venue_code, race_date, race_number, COUNT(*) as cnt
FROM races
WHERE race_date LIKE '2023-12%'
GROUP BY venue_code, race_date, race_number
HAVING cnt > 1
ORDER BY cnt DESC
LIMIT 10;
```

**対策**:
- 重複レコードの特定と削除
- 関連テーブル（entries, results等）の整合性確認

#### 3. 過去データの低充足率

2020-2023年のデータは、レース基本情報は存在するものの、詳細データが大幅に不足。

**原因の可能性**:
- データ収集スクリプトの途中中断
- APIアクセス制限による取得失敗
- データ保存時のエラー
