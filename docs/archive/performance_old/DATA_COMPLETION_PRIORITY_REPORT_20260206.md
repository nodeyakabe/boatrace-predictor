## ⚠️ 重要な注意事項

1. **決まり手データ（kimarite）補完後の必須作業**
   - `kimarite_flow_stats.json`の再生成が必要
   - 統計ファイル生成スクリプトの作成または既存スクリプトの実行

2. **天候データ（weather）の使い方**
   - race_conditions.weatherカラムは無視
   - **weatherテーブル**を直接使用
   - venue_code + weather_dateで結合

3. **prev_race_rankの補完方法**
   - APIから取得するのではなく、resultsテーブルから計算
   - 同日前レースの着順を取得して格納

4. **補完の優先順位は柔軟に変更可能**
   - TJ-2, TJ-3などの分析タスクの実施予定に応じて調整
   - データ補完完了後に効果検証を実施
