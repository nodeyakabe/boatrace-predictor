## Phase 2-1: 会場フィルター過学習検証

### 検証方法

2024年と2025年のデータを用いて、会場フィルターの年度間一貫性を検証した。

**検証手順**:
1. 2024年・2025年それぞれの会場別ROIを算出
2. 年度間ROI相関係数（Pearson's r）を計算
3. ROI好調会場の一致率を測定
4. 過学習リスクの定量評価

**使用データ**:
- 2024年: before予測データ（部分的）
- 2025年: before予測データ（936件 → 947件）

### 結果詳細

#### 年度間ROI相関分析

| 指標 | 値 | 判定 |
|------|-----|------|
| Pearson相関係数 r | **0.077** | 相関なし |
| p値 | **0.79** | 統計的に無意味 |
| 判定基準 | r > 0.5 かつ p < 0.05 | 不合格 |

**解釈**: 2024年でROIが高かった会場が2025年でも高いという関係性は**全く認められない**。

#### ROI好調会場の一致率

| 項目 | 2024年 | 2025年 | 両年一致 |
|------|--------|--------|----------|
| ROI 100%超の会場数 | 11会場 | 9会場 | **2会場のみ** |
| 一致率 | - | - | **22%** |

**解釈**: Tier1として選定された好調会場の78%は、2024年では好調ではなかった。

#### 過学習リスク評価

| リスク要因 | レベル | 詳細 |
|-----------|--------|------|
| 年度間一貫性 | **致命的** | r=0.077で相関なし |
| Tier1の再現性 | **高** | 22%しか再現しない |
| 統計的有意性 | **高** | p=1.0（完全に無意味） |
| データ偏り | **中** | 2024年データが不完全 |

### 判定理由

**判定: 不採用**

1. **年度間相関がほぼゼロ（r=0.077）**
   - 2025年で好調な会場が2024年でも好調という証拠がない
   - 単年度の偶然の結果である可能性が極めて高い

2. **ROI好調会場の一致率が低い（22%）**
   - 福岡421.8%、琵琶湖372.8%などのTier1会場は2025年固有の現象
   - 2024年以前には同様の傾向が見られない

3. **統計的有意性なし（p=1.0）**
   - t検定でp値が1.0（完全に有意差なし）
   - 効果量Cohen's d = 0.0（改善効果ゼロ）

4. **過学習の典型的兆候**
   - 単一年度のデータで最適化された分類
   - 将来のパフォーマンスを保証できない

## Phase 2-2: A/Bテスト再検証

### サンプル数の変化

| 項目 | 前回 | 今回 | 変化 |
|------|------|------|------|
| 総サンプル数 | 936件 | 947件 | **+11件（+1.2%）** |
| Control | - | 493件 | - |
| Treatment A | - | 222件 | - |
| Treatment B | - | 221件 | - |

**注**: サンプル増加は微小（+1.2%）であり、統計的検出力への影響は限定的。

### 統計的検定結果

#### Treatment A: 会場×コース勝率テーブル

| 指標 | 値 | 判定基準 | 結果 |
|------|-----|---------|------|
| Control ROI | 116.9% | - | - |
| Treatment A ROI | 142.5% | - | - |
| ROI差 | **+7.7pt** | - | 改善傾向 |
| t値 | 0.11 | - | - |
| **p値** | **0.91** | p < 0.05 | **不合格** |
| 判定 | - | 統計的有意性 | **有意差なし** |

#### Treatment B: 天候強化特徴量

| 指標 | 値 | 判定基準 | 結果 |
|------|-----|---------|------|
| Control ROI | 116.9% | - | - |
| Treatment B ROI | 91.7% | - | - |
| ROI差 | **-34.2pt** | - | 悪化傾向 |
| t値 | -0.57 | - | - |
| **p値** | **0.57** | p < 0.05 | **不合格** |
| 判定 | - | 統計的有意性 | **有意差なし** |

### 検出力分析

| 項目 | 必要数 | 実数 | 状況 |
|------|--------|------|------|
| 効果量0.3検出に必要なサンプル | 174件/群 | - | 基準 |
| Control | 174件以上 | 493件 | **OK** |
| Treatment A | 174件以上 | 222件 | **OK** |
| Treatment B | 174件以上 | 221件 | **OK** |

**注**: サンプル数は十分だが、ROI分散が大きいため検出力が不足。

### 判定理由

**判定: 現状維持（特徴量変更なし）**

1. **両Treatment群とも統計的有意性なし**
   - Treatment A: p=0.91（完全にランダムノイズの範囲）
   - Treatment B: p=0.57（同様）

2. **改善傾向は見られるが確証なし**
   - Treatment Aは+7.7pt改善傾向だが、偶然の可能性が91%
   - 採用するには証拠が不十分

3. **天候強化特徴量は悪化傾向**
   - -34.2ptの悪化傾向
   - ただし統計的有意性がないため、断定は避ける

4. **現状維持が最も安全**
   - 現行システムROI 167%を維持
   - 不確実な変更によるリスクを回避

| 5 | **会場** | Tier1/2/3、24会場個別 | 会場特性の活用方法 |
| 6 | **交差分析** | 信頼度×会場×コース等 | 複合条件での最適化 |

| 施策 | 全体効果 | 局所検証の仮説 |

### 今後の実施推奨

**優先度: 中（Phase 3として実施推奨）**

**理由**:
1. 全体最適化より局所最適化の方が効果を見出しやすい可能性
2. 特定条件での「勝ちパターン」発見の期待
3. 既存データで実施可能（追加コスト低）

**推奨実施順序**:
1. 信頼度別分析（最も効果が期待される）
2. オッズ帯別分析（収益直結）
3. 予測コース別分析（戦略改善）
4. 交差分析（複合最適化）

## 統計的検証の教訓

### Phase 2で確立した検証基準

| 基準 | 閾値 | 意味 |
|------|------|------|
| **統計的有意性** | p < 0.05 | 5%未満の偶然確率 |
| **年度間相関** | r > 0.5 | 中程度以上の相関 |
| **効果量** | Cohen's d > 0.2 | 小さい効果以上 |
| **サンプル数** | 174件/群以上 | 効果量0.3検出可能 |

### 今後の施策評価フロー

```
1. バックテストでROI改善を確認
   ↓
2. 統計的有意性検定（p < 0.05）
   ↓ 合格
3. 年度間一貫性検証（r > 0.5）
   ↓ 合格
4. 効果量確認（d > 0.2）
   ↓ 合格
5. 採用
```

**全ての基準を満たさない限り、施策は採用しない。**
