| 2025 | 25,041 | 552 | **2.2%** |
| **全期間** | **303,576** | **708** | **0.2%** |

**予測ロジックでの扱い**:

```python
# extended_scorer.py Line 1465-1474
if not times_data or len(times_data) == 0:
    # データなしの場合は中立点
    return {
        'score': max_score * 0.5,  # 4.0 * 0.5 = 2.0点
        'chikusen_time': None,
        'rank': None,
        'level': 'unknown',
        'description': '直線タイムデータなし'
    }
```

**実態**:
- データありの場合（0.2%）: 順位でスコア差別化（1位=4.0点、6位=0点）
- **データなしの場合（99.8%）: 全選手に一律2.0点** → **差別化できない**

**重大な問題**:
- 重み設定: `max_score=4.0`（比較的大きい）
- しかし実際は**99.8%のレースで無意味**
- 効果測定が不可能（データがないため）
