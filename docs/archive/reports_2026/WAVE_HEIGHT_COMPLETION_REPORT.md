## 🎯 推奨アクション

### 優先度A（即座に対応すべき）

#### 1. 2020年9月の異常な日付形式の修正

**問題**:
- 3,000件のレースデータが「YYYYMMDD」形式で登録
- 正しい「YYYY-MM-DD」形式に修正が必要
- これらのレースにrace_conditionsが紐づいていない

**対応スクリプト**:
```bash
python scripts/maintenance/fix_abnormal_dates.py
```

**実施内容**:
1. 異常な日付形式のrace_idを検出
2. 「YYYYMMDD」→「YYYY-MM-DD」に変換
3. race_conditionsの紐付けを再実行

## 📝 技術的詳細

### 補完方法

1. **CSV生成**: 公式APIから年度別にrace_conditionsを一括取得
2. **重複排除**: 既存データとの重複を除外
3. **DB投入**: `INSERT OR REPLACE`でデータを投入

### データソース

- **公式API**: https://www.boatrace.jp/owpc/pc/race/raceindex
- **取得項目**: weather, wind_direction, wind_speed, wave_height, temperature, water_temperature

### 投入スクリプト

```bash
# 2020年データ投入
python scripts/data_collection/save_race_conditions_csv_to_db.py \
    --csv data/csv/race_conditions/2020/race_conditions.csv

# 2021年データ投入
python scripts/data_collection/save_race_conditions_csv_to_db.py \
    --csv data/csv/race_conditions/2021/race_conditions.csv
```
