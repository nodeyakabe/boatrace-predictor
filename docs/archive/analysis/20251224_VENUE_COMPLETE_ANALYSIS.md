## 2. 環境要因分析

### 2.1 風速の影響

#### 全体傾向

| 風速 | 1C勝率 | 4-6C勝率 | レース数 |
|------|--------|---------|----------|
| 0-2m | 58.5% | 18.2% | 40,475 |
| 2-4m | 57.1% | 19.4% | 30,780 |
| 4-6m | 55.3% | 21.0% | 14,099 |
| 6m以上 | 52.8% | 23.5% | 4,045 |

**法則**: 風速が上がるほど1コース勝率は低下し、外コースが有利に

#### 会場別風速影響度

**強風で荒れやすい会場**:
- 浜名湖: 弱風60.7% → 強風40.0% (差-20.7pt)
- 常滑: 弱風62.5% → 強風50.6% (差-11.9pt)
- 唐津: 弱風59.8% → 強風47.8% (差-11.9pt)

**強風で安定する会場**:
- 大村: 弱風67.2% → 強風77.6% (差+10.4pt)
- 蒲郡: 弱風53.4% → 強風54.2% (差+0.8pt)
- 丸亀: 弱風63.4% → 強風64.2% (差+0.8pt)

### 2.2 波高の影響

| 波高 | 1C勝率 | 特徴 |
|------|--------|------|
| 0-2cm | 58.2% | 安定 |
| 2-5cm | 55.8% | やや荒れ |
| 5cm以上 | 52.3% | 荒れる |

**法則**: 波が高いとターン時に不安定になり、外コースにチャンス
