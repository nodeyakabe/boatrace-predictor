## 📊 調査結果（確定）

### 不一致の根本原因

**逃げ率（escape_rate）のNULL処理の違い**が24%不一致の主原因です。

| 処理 | Tier 2（SQL） | Tier 3（Python） | 結果 |
|------|--------------|-----------------|-----|
| **逃げ率がNULLの場合** | 暗黙的に除外（挙動不明確） | **明示的に除外** | **不一致** |
| **バイアス指数がNULLの場合** | `IS NOT NULL`で明示的に除外 | 明示的に除外 | 一致 |

**該当条件**: A×A1×10-12（逃げ率>=70%）
**影響レース数**: 150-600件/6年間（推定）
**不一致への寄与**: 約15-20%ポイント

  - 除外理由: 1件（1.0%） - オッズデータなし

### 具体的レース分析（5件）

全サンプルで以下を確認:
- Tier 2の基本フィルター（信頼度×級別）は通過
- **各条件の詳細フィルター（オッズ範囲、会場、逃げ率等）で除外**
- Tier 3でも同じ理由で除外

**結論**: Tier 2のSQLは条件ごとに正しくフィルターを適用している。問題は**NULL処理の違い**のみ。

## 🛠 修正案（1行の追加）

### ファイル: `scripts/backtest/standard_backtest.py`

**Line 219**: 逃げ率フィルターに `IS NOT NULL` を追加

**修正前**:
```python
escape_rate_clause = f"AND pes.escape_rate >= {cond['escape_rate_min']} "
```

**修正後**:
```python
escape_rate_clause = f"AND pes.escape_rate IS NOT NULL AND pes.escape_rate >= {cond['escape_rate_min']} "
```
