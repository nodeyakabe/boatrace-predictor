|------|---:|
| レース数 | 102,792件 |
| 的中内訳 | |
| └ ① 1-2-3 | 6,465件 |

| └ ③ 1-2-4 | 5,134件 |

| 投資額 | 41,116,800円 |

**発見: 1-3-2（2着と3着入れ替え）が5,306件的中**
- 全的中の31.4%を占める
- 「2着予測が外れやすい」ことを補完

### 結果（信頼度B限定）

| パターン | 的中率 | ROI | 収支 | 平均配当 |
|---------|-------:|----:|-----:|---------:|
| **🥇 現行（本命厚め）** | 17.6% | **80.8%** | **-982,760円** | 14.0倍 |
| 🥈 均等3点買い | 17.6% | 78.7% | -1,090,418円 | 14.0倍 |

### 差額比較

| 比較 | 収支差 | ROI差 |
|------|-------:|------:|
| 現行 vs 均等 | **+107,658円** | **+2.1pt** |
| 現行 vs 4点 | **+232,670円** | **+4.5pt** |

### 重要な洞察

1. **本命厚め（現行）が最良**
   - 予測3着の的中率が最も高い
   - 高確率の買い目に資金集中 = 効率的

2. **均等買いは非効率**
   - 本命も保険も同額 → 効率悪化
   - ROI -2.1pt

3. **4点買いは的中率↑でもROI↓**
   - 的中率: 17.6% → 20.0% (+2.4pt)
   - ROI: 80.8% → 76.3% (-4.5pt)
   - 収支: -232,670円悪化

4. **買い目を増やすほど非効率**

#### 2. 「機会損失」は誤解

**ユーザーの懸念:**
> 1点買いで9,052レースの的中を逃している（機会損失）

**実際のデータ:**

| 項目 | 金額 |
|------|-----:|
| 3点買いで追加的中 | 9,052レース |

| **実際に回収できる金額** | **15,734,780円（25%のみ）** |

**理由:**
- 3点買いは不的中レースでも400円全損
- 1点買いは不的中レースで100円損失のみ
- 不的中レース（79,564レース）のコスト差が大きい

**結論:**
機会損失ではなく、「追加投資のコストが払戻を上回る」
