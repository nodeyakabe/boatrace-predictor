## 2. D×5コース予測 詳細分析

### なぜ5コース予測が有効か

1. **アウトコースの特殊性**: 5コース（アウト）は通常不利だが、予測時に1着と判定されるケースは特殊な好条件（スタート力、モーター性能、展開予想）が揃っている
2. **希少価値**: 5コース1着予測自体が少ないため、予測された場合の信頼度が高い
3. **高オッズ傾向**: アウト予測のため平均オッズが高く、的中時のリターンが大きい

## 3. 浜名湖条件の削除理由

### 問題の発見

| データソース | 件数 | ROI |
|:-------------|:----:|:---:|
| ml_analysis_features | 600件 | 201.4% |
| standard_backtest | **0件** | - |

### 原因

- `ml_analysis_features` テーブルと `race_predictions` テーブル間でデータ差異が存在
- `standard_backtest.py` は `race_predictions` を直接参照するため、該当条件のレースが0件

### 対応

- bet_target_evaluator.py から浜名湖×D×50-100×B1 条件を削除
- 以下のコメントを残置:
  ```python
  # 【2026-01-05追加→削除】浜名湖(06)×D×50-100倍×B1
  # ※ standard_backtest検証で該当レース0件のため削除
  # ml_analysis_featuresとrace_predictionsでデータ差異あり
  ```
