## エグゼクティブサマリー

### 現状の予測精度

| 予測順位 | 目標着順 | 的中率 | 評価 |
|---------|---------|-------|------|
| **予測1位** | 1着 | **51.86%** | ✅ 高い |
| **予測2位** | 2着 | **25.71%** | ⚠️ まあまあ |
| **予測3位** | 3着 | **20.69%** | ❌ 低い（問題） |

**目標**: 予測3位の3着的中率を 20.69% → **30%以上**に向上

### 主要な発見

#### 1. 予測3位の3着的中率が低い原因

1. **1号艇（インコース）予測3位の的中率が極端に低い**
   - 的中率: **10.50%** （全体平均の半分以下）
   - 1号艇を予測3位にした場合、実際の平均着順は **2.28着**
   - **インコースは1着になりやすいため、3着予測は不適切**

2. **B2級の選手を予測3位にした場合の的中率が低い**
   - B2級: **15.57%** （A1/A2の約70%）
   - 実際の平均着順: **4.03着** （3着より大きく後退）

3. **会場によって精度に大きなバラツキがある**
   - 最高: 津（09）**22.94%**
   - 最低: 多摩川（05）**17.89%**
   - 差: **5.05ポイント**

4. **予測3位が外れた時、4位以下に沈むことが多い**
   - 3着的中: 20.69%
   - 4着以下: **46.07%** （半数近くが3着を逃す）
   - 1着/2着に浮上: 33.24% （意外と好走）

#### 2. 実際に3着に来るのは誰か

| 予測順位 | 3着に来る割合 | 評価 |
|---------|-------------|------|
| 予測3位 | 20.34% | ← 目標値 |
| **予測2位** | **19.33%** | ⚠️ 予測3位とほぼ同じ |
| **予測4位** | **19.35%** | ⚠️ 予測3位とほぼ同じ |
| 予測5位 | 17.17% | |
| 予測6位 | 12.86% | |
| 予測1位 | 10.48% | 番狂わせ |

**重要な発見**: 予測2位、3位、4位が3着に来る確率がほぼ同じ（約19-20%）
→ **3着予測の精度が不十分**

### 改善の方向性

1. **インコース（1号艇）を予測3位にしない**
   - 期待効果: +2-3%
   - 1号艇は1着/2着予測に優先配分

2. **B2級選手の予測順位を下方修正**
   - 期待効果: +1-2%
   - B2級を3位にする基準を厳格化

3. **会場別の特性を考慮**
   - 期待効果: +0.5-1%
   - 多摩川、戸田、浜名湖などで予測精度が低い会場の対策

4. **予測2位と4位の精度向上**
   - 現状、2位/3位/4位の区別が曖昧
   - 3着候補の絞り込み精度を上げる

#### 施策1: インコース（1号艇）を予測3位から除外

**現状の問題**:
- 1号艇を予測3位にした場合の的中率: **10.50%** （全体平均の半分以下）
- 実際の平均着順: **2.28着** （3着より上）

**改善策**:
- 1号艇は3位予測から除外
- 1号艇は1位/2位予測に優先配分
- 特に1号艇がA1級の場合は1位予測を強化

**期待効果**: **+2-3%** （10.50% → 12-13%）

#### 施策2: B2級選手の3位予測を厳格化

**現状の問題**:
- B2級を予測3位にした場合の的中率: **15.57%** （A級の約70%）
- 実際の平均着順: **4.03着** （3着より大きく後退）

**改善策**:
- B2級を3位予測にする基準を厳格化
- B2級は4位以下の予測に配分
- ただし、B2級でもモーター性能が良い場合は例外とする

**期待効果**: **+1-2%** （15.57% → 17-18%）

#### 施策3: 会場別の補正係数を導入

**現状の問題**:
- 会場による精度差が約5ポイント（17.89% ~ 22.94%）
- 多摩川、戸田、江戸川などの難水面で精度が低い

**改善策**:
- 会場別の補正係数を導入
- 精度が低い会場では予測順位を調整
- 会場特有のパターン（風の影響、水面特性など）を学習

**期待効果**: **+0.5-1%**

#### 施策4: 3着候補（予測2位/3位/4位）の絞り込み精度向上

**現状の問題**:
- 予測2位/3位/4位が3着に来る確率がほぼ同じ（19-20%）
- 3着候補の絞り込みが不十分

**改善策**:
- 以下の要素を強化:
  - コース別の3着率（3号艇・4号艇が有利）
  - 級別の影響（A級が有利）
  - ST（スタートタイミング）の安定性
  - 決まり手データの活用（まくり/差しの傾向）
- 機械学習モデルの特徴量を見直す

**期待効果**: **+2-3%**

#### 施策5: 展示タイム・モーター性能の重み付け見直し

**現状の問題**:
- 展示タイム・モーター性能は1着予測には有効だが、3着予測には効果が薄い

**改善策**:
- 3着予測には、展示タイム・モーター性能の重みを下げる
- 代わりに以下の要素を重視:
  - コース取り（進入隊形）
  - ST（スタートタイミング）
  - 決まり手傾向
  - 選手の「3着率」（過去の成績）

**期待効果**: **+1-2%**

### 5.2 追加すべき特徴量

1. **進入隊形データ**
   - 実際の進入コース（actual_course）
   - 枠番と進入コースのズレ

2. **STタイミングの安定性**
   - 平均STだけでなく、ST のバラツキ（標準偏差）
   - ST遅れのリスク

3. **決まり手データの活用**
   - 「逃げ」「まくり」「差し」の傾向
   - 会場別の決まり手傾向

4. **選手の「3着率」**
   - 過去の成績から「3着に来る確率」を算出
   - 現状は勝率・2連率のみを使用

5. **レース展開予測**
   - 1着候補が逃げ切る確率
   - 2-6号艇の混戦度合い

### 5.3 モデルの改善方向性

#### 現在のモデルの問題点

1. **1着予測に偏重**
   - 展示タイム・モーター性能など、1着予測に有効な指標を重視
   - 3着予測には別のアプローチが必要

2. **コース別の特性が不十分**
   - 1号艇を3位予測にする問題
   - 3号艇・4号艇が3着予測に適していることが考慮されていない

3. **級別の影響が不十分**
   - B2級を3位予測にする問題
   - A級とB級の差が反映されていない

#### 改善アプローチ

1. **3着予測専用のモデルを構築**
   - 1着予測モデルとは別に、3着予測モデルを作成
   - 3着に来やすい選手の特徴を学習

2. **ルールベースの制約を追加**
   - 1号艇は3位予測から除外（ハードルール）
   - B2級は4位以下に優先配分（ソフトルール）

3. **アンサンブル学習の活用**
   - 複数のモデルを組み合わせて予測精度を向上
   - コース別・級別のサブモデルを作成

## まとめ

### 予測3位の3着的中率が低い原因（再掲）

1. **1号艇（インコース）を予測3位にすると的中率が極端に低い（10.50%）**
2. **B2級選手を予測3位にすると的中率が低い（15.57%）**
3. **会場による精度差が大きい（17.89% ~ 22.94%）**
4. **予測2位/3位/4位が3着に来る確率がほぼ同じ（19-20%）で、絞り込みが不十分**

| 中 | 展示タイム・モーター性能の重み見直し | +1-2% | 中 |

**合計期待効果**: **+7-11%** （20.69% → **27-31%**）
