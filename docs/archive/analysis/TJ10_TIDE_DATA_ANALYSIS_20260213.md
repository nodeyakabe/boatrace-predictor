## IV. 重要な課題と制限事項

### 1. 潮位フェーズ判定の信頼性

**問題点**:
- `_determine_tide_phase()`メソッドが10分前後の変化傾向で判定
- 1分間隔データで前後10レコード（10分幅）を使用
- 満潮・干潮の判定が相対的（データの平均との比較）
- 正確な満潮時刻は計算されていない

**影響**:
- フェーズ判定の不正確さ → 補正の過不足
- 特に満潮・干潮付近での判定エラーリスク

### 2. 補正係数の根拠の限定性

**観察**:
- 会場17（徳山）: +14.7%の差分を根拠に+7%を適用（「差分の半分」説明）
- 分析ベースが限定的（分析年度・期間不明）
- チューニングの余地あり

### 3. 統計的有意性の確認不足

**未確認項目**:
- ❌ TideAdjusterが**実際に有効か**（ON/OFF比較なし）
- ❌ 各会場で**統計的に有意か**（サンプル数確認なし）
- ❌ **各潮位フェーズ別パフォーマンス**（定量データなし）

### 4. データ欠損時の処理

**潮位データ取得失敗時**:
```
→ 補正なし（自動フォールバック）
```

**発生状況**:
- 海水会場外: 取得しない
- 対応観測所なし: 取得しない
- 潮位データなし（時間外など）: 取得しない

**影響評価**: 軽微（99.6%レースでオッズ利用可能）
