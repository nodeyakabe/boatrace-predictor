## 4. 問題点の特定

### 4.1 直前情報が効いていない原因

1. **信頼度の維持率が100%**
   - advance -> before で信頼度が全く変化していない
   - 「C (維持)」9,400件、「D (維持)」4,783件など
   - 直前情報がスコアに反映されても、順位変動が起きていない

2. **重み付けの問題**
   - `BEFORE_SCORE * 0.4` でも、事前スコアとの相関が高すぎる
   - 良い選手は展示も良い傾向があり、差別化要因になっていない

3. **スコアリングの問題**
   - 展示タイム: 相対順位で評価（1位25点、2位18点...）
   - 全艇に同じ基準を適用しているため、差がつきにくい

### 4.2 具体的な問題箇所

```python
# beforeinfo_scorer.py L18
最終統合: FINAL_SCORE = PRE_SCORE * 0.6 + BEFORE_SCORE * 0.4
```

- 40%の重みは大きいが、事前予測と直前予測の相関が高すぎる
- 直前情報が「予想を覆す」情報として機能していない

## 5. 改善提案

### 5.1 短期改善策

1. **差分ベースのスコアリング**
   - 「事前予測との乖離」を評価する
   - 例: 事前予測4位の選手が展示1位なら大きく加点

2. **閾値ベースのボーナス**
   - 特定条件を満たした場合のみ加点
   - 例: ST 0.10秒以下 + 展示タイム1位 → +10点

### 5.2 中期改善策

1. **直前情報の重みを条件付きに**
   - 予測が不安定なレース（信頼度D/E）でのみ直前情報の重みを上げる
   - 信頼度A/Bでは直前情報の影響を下げる

2. **異常値検出**
   - 展示タイムの大幅な乖離（例: 6艇中6位→1位）を重視
   - 通常時は直前情報の影響を小さくする

### 5.3 長期改善策

1. **機械学習による最適化**
   - 直前情報の各要素の重みを学習
   - 的中時/非的中時の直前情報パターンを分析

2. **予測モデルの分離**
   - 事前予測モデルと直前予測モデルを完全に分離
   - アンサンブルで統合

---

## 6. 結論

### 6.1 現状の評価
- **直前情報は予測精度向上にほぼ寄与していない**
- 40%もの重みをかけているにもかかわらず、改善効果は0.04pt程度
- 115点満点のスコアリングシステムは機能していない

### 6.2 推奨アクション
1. 直前情報の重みを一時的に下げる（0.4 → 0.2）
2. 差分ベースのスコアリングを検討
3. 機械学習による最適化を長期課題として計画
