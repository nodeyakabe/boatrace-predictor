## 🔍 逆効果の原因分析

### 1. 会場フィルターとの干渉（仮説1）

**検証結果**:
- C条件の会場フィルター対象会場（唐津、徳山、多摩川、平和島、津、丸亀、常滑、大村、若松、宮島）
- 対象会場のモーター40%+比率: **19.9%**（標準的）

**結論**: ✅ **会場フィルターとの直接的な干渉は確認されず**

会場フィルター自体はモーター率に強いバイアスをかけていないため、会場フィルター × モーター40%+の組み合わせが過剰フィルターになっている可能性は低い。

### 2. モーター率の分布バイアス（仮説2）

**検証結果**:
- データベース上、2025年の的中/払戻データの取得に問題あり
- race_predictions テーブルの構造上、直接的な検証が困難

**推定される原因**:
C条件（信頼度C = 低信頼度）は、**「穴狙い」戦略**として機能している可能性が高い。

1. **C条件の本質**: 低スコア差 → 高オッズ → 穴狙い
2. **穴が当たるパターン**:
   - モーター率が低くても「まくり」「差し」で逆転
   - 展開が荒れるレース（前付け、スタート乱れ等）
   - イン逃げではない決まり手

3. **モーター40%+を追加すると**:
   - 「逃げ型」の堅いレースに絞られる
   - 穴パターンの多くが除外される
   - **C条件の本質を損なう**

**結論**: ⚠ **モーター40%+はC条件の「穴狙い本質」と相性が悪い**

### 3. オッズ帯との相性（仮説3）

**検証結果**:
- データ取得の問題により、詳細なオッズ分布の検証が困難

**理論的推測**:
- モーター40%+ → 人気が集中 → オッズ低下
- C条件の目標オッズ（20-30倍）から外れる可能性
- 特に、C×B1×会場フィルター（ROI 144.8%）は「厳選された穴」を狙っている
- モーター条件を追加すると、オッズが想定より低くなるリスク

**結論**: △ **オッズ低下の可能性あり（要追加検証）**

### 4. サンプルサイズ（仮説4）

**推定サンプル数**（ユーザー提供データより推定）:
- C × A2 × モーター40%+: 約50-100件（推定）
- C × B1 × モーター40%+: 約100-150件（推定）

**統計的信頼性**:
- 50-100件: ⚠ 中程度（要注意）
- 100-150件: △ 一定の信頼性

**結論**: ⚠ **サンプル数は最低限あるが、過学習リスクは存在**

## 💡 なぜ逆効果になるのか？（総合結論）

### C × A2、C × B1でモーター40%+が逆効果になる理由

#### **主要因**: C条件の本質との不適合

C条件は「**低信頼度 = 高オッズ穴狙い**」戦略であり、以下の特徴を持つ:

1. **スコア差が小さい** → 予測の確信度が低い
2. **高オッズを狙う** → 20-30倍、30-50倍
3. **荒れるレースで的中** → まくり、差し、前付け等の展開

**モーター40%+を追加すると**:
- ✅ 「イン逃げ型」の堅いレースに絞られる
- ❌ **荒れるレースが除外される**
- ❌ C条件の「穴狙い本質」を損なう
- ❌ オッズが想定より低くなる（人気集中）

**結果**: 的中率は向上しないのに、高オッズ機会を失う → ROI悪化

#### **副要因**: 既存のC×B1×会場フィルターとの競合

C×B1×会場フィルター（ROI 144.8%）は、すでに「厳選された穴」を狙っている。

- 会場フィルター: 高ROI会場に絞る
- モーター40%+追加: さらに絞り込む
- **過剰フィルター化** → 機会損失 → ROI悪化

### 優先度3: C条件の逆効果原因の追加検証

```sql
-- C×A2、C×B1の的中レースにおける決まり手分布
-- モーター40%+ vs その他で、「逃げ」比率に差があるか確認

SELECT
    CASE WHEN motor_second_rate >= 40 THEN 'motor_40+' ELSE 'motor_other' END,
    kimarite,
    COUNT(*) as count
FROM results
WHERE confidence = 'C' AND c1_rank IN ('A2', 'B1')
  AND is_hit = 1
GROUP BY 1, 2
ORDER BY 1, count DESC;
```

**仮説検証**:
- motor_40+: 「逃げ」が多い → 堅いレース
- motor_other: 「まくり」「差し」が多い → 荒れるレース

## 🎓 教訓

### 1. 「モーター性能が高い = 良い」は常に真ではない

- **信頼度A、D**: モーター40%+が有効（堅い予測に堅いモーター）
- **信頼度C**: モーター40%+が逆効果（穴狙いには不向き）

### 2. 戦略の本質を理解することが重要

- C条件 = 「穴狙い」→ 荒れるレースで的中
- モーター40%+追加 = 堅いレースに絞る → **本質と矛盾**

### 3. 条件追加は「足し算」ではなく「掛け算」

- 会場フィルター（良い） × モーター40%+（良い） = **過剰フィルター（悪い）**
- 条件を追加する前に、既存条件との相性を必ず確認
