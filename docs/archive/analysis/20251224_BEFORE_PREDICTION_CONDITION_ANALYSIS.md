## 6. 赤字年の深掘り分析

### 6.1 2021-2022年の傾向

複数条件で2021-2022年がゼロまたはマイナスになっている。

**考えられる原因**:
1. **コロナ禍の影響**: 2021年は無観客開催が多く、レース傾向が変化
2. **選手・モーターの入れ替え時期**: 期初めの不安定性
3. **予測モデルのドリフト**: 学習データと実データの乖離

**対策**:
- 2021-2022年データを除外した再検証
- 会場別の影響分析
- 時期（月別）フィルターの検討

### 6.2 サンプル数不足による偶然

| 条件 | ゼロ年のサンプル数 | 評価 |
|------|-------------------|------|
| B×50-100×A1 | 17件（2021）、2件（2022） | **偶然の可能性高** |
| B×50-100×B1 | 16件（2021）、9件（2022） | **偶然の可能性あり** |
| D×40-50×B1 | 32件（2021）、148件（2022） | 2022年は構造的問題か |

### 注意事項

3. **資金管理**: 複数条件を運用する場合は1レースあたりの投資額を調整
4. **モニタリング**: 月次でROIを確認し、継続的にマイナスなら停止
