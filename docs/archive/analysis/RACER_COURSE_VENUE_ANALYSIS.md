## 6. 予測ロジックへの活用方法

### 6.1 現在の実装状況

| 機能 | 実装ファイル | 状態 |
|------|-------------|------|
| 選手全体成績 | `src/analysis/racer_analyzer.py` | ✅ 稼働中 |
| コース別成績 | `get_racer_course_stats()` | ✅ 稼働中 |
| 会場別成績 | `get_racer_venue_stats()` | ✅ 稼働中 |
| 直近成績 | `get_racer_recent_form()` | ✅ 稼働中 |

### 6.2 改善提案

#### 提案1: 選手タイプに基づくスコア調整

```python
# インコース専門型（Type A）の場合
if racer_type == 'inside_specialist' and course == 1:
    score_bonus = +5pt
elif racer_type == 'inside_specialist' and course >= 4:
    score_penalty = -3pt

# アウトコース巧者（Type B）の場合
if racer_type == 'outside_specialist' and course >= 4:
    score_bonus = +3pt
```

#### 提案2: 会場×選手の相性スコア

```python
# 得意会場判定（全体勝率との差が+15pt以上）
if venue_advantage > 15:
    score_bonus = +3pt
elif venue_advantage < -15:
    score_penalty = -3pt
```

#### 提案3: 会場×コース×選手の複合評価

```python
# 特定会場の特定コースで高勝率の場合
if venue_course_win_rate > 80 and venue_course_races >= 10:
    confidence_boost = True  # 信頼度A/B判定の加点
```
