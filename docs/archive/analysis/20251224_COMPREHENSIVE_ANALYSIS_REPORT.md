## エグゼクティブサマリー

### 結論

**今回の「改善」は実質的には改善していない。ROI向上は購入件数を632件減らした結果であり、真の改善とは言えない。**

| 指標 | 前回（12/20） | 今回（改善後） | 差 | 評価 |
|:--|:--:|:--:|:--:|:--:|
| 購入件数 | 1,734件 | 1,102件 | **-632件** | ❌ 36%減少 |
| ROI | 107.8% | 127.3% | **+19.5pt** | ✅ 向上 |
| 収支 | +13,570円 | +30,120円 | **+16,550円** | ✅ 向上 |
| 的中数 | 76回 | 56回 | **-20回** | ❌ 26%減少 |

**真の評価**:
- 収支改善+16,550円は歓迎すべき
- しかし、購入機会を-632件（36%）も失った代償が大きすぎる
- 件数あたり収支: 前回7.8円/件 → 今回27.3円/件（+19.5円/件改善）← これが真の改善幅

**結論**: 2025年は例外的に悪いのではなく、A条件は**構造的に収益性が低い**。

## 2. 前回より全体収支が下がった真の原因

### 条件別の変化

| 条件 | 前回件数 | 前回収支 | 今回件数 | 今回収支 | 差 |
|:--|:--:|:--:|:--:|:--:|:--:|
| **A×A1×10-20** | 522 | -7,150円 | 522 | -7,150円 | **±0** |
| **B×50-100** | 52 | +9,840円 | 52 | +9,840円 | **±0** |
| **B×30-50×B1+会場** | - | - | 20 | **+9,040円** | **+9,040円** |
| **C×30-40×B1/A1** | 444 | -3,840円 | - | - | **-3,840円失う** |
| **D×20-50（旧）** | 716 | +14,720円 | - | - | **-14,720円失う** |
| **D×30-60（新）** | - | - | 508 | **+18,390円** | **+18,390円** |

### 真の原因

1. **C条件削除で-3,840円失った**
   - C×30-40×B1/A1: 444件、12的中、ROI 91.4%
   - 赤字だが、購入機会444件を捨てた

2. **D条件の範囲変更で収支が改善**
   - 旧D×20-50: 716件、+14,720円
   - 新D×30-60: 508件、+18,390円
   - **件数は-208件減ったが、収支は+3,670円改善**
   - 低オッズ帯（20-30倍）を切り捨てた効果

3. **B×30-50×B1+会場フィルターが絶大**
   - わずか20件で+9,040円
   - ROI 552.0%（驚異的）
   - 会場フィルター（10会場限定）が効いている

### 本質的な問題

**前回の条件は「広く浅く」、今回の条件は「狭く深く」**

| 指標 | 前回（広く浅く） | 今回（狭く深く） |
|:--|:--:|:--:|
| 購入機会 | 多い（1,734件） | 少ない（1,102件） |
| ROI | 低い（107.8%） | 高い（127.3%） |
| リスク | 分散 | 集中 |

## 3. 現在の条件設定で問題がある箇所

### 問題点1: A条件（A×A1×10-20）を含めている

| 指標 | 値 |
|:--|:--:|
| 6年間ROI | **89.0%**（赤字） |
| 2025年ROI | 91.0%（赤字） |
| 6年間収支 | **-23,295円** |
| 2025年収支 | -7,150円 |

**判定**: **即時削除すべき**

### 問題点2: C条件を完全削除したのは早計

前回のC×30-40×B1/A1:
- 444件、12的中、ROI 91.4%、収支-3,840円
- 赤字ではあるが、的中12回は貴重
- オッズ帯や会場を絞れば改善の余地あり

**新たに発見されたC条件（before予測）**:
- C×20-30×B1 + 会場フィルター: ROI **144.8%**（6年間）
- 2025年のみ: ROI 73.3%（赤字）だが、6年間では黒字

**判定**: **C条件の復活を検討すべき（ただし会場フィルター付き）**

### 問題点3: D条件の範囲が狭すぎる可能性

| 条件 | 件数 | ROI | 収支 |
|:--|:--:|:--:|:--:|
| D×20-50（旧） | 716件 | 120.6% | +14,720円 |
| D×30-60（新） | 508件 | 136.2% | +18,390円 |
| **差** | **-208件** | **+15.6pt** | **+3,670円** |

- 件数を-208件減らして+3,670円改善
- 件数あたり収支: 旧20.6円/件 → 新36.2円/件（+15.6円/件改善）

**問題**: D×20-30の中に「赤字レース」が混ざっていた可能性が高い

**検証課題**: D×20-30を切り捨てた影響を、6年間データで再検証すべき

### 問題点4: B×30-50×B1+会場フィルターのサンプル数不足

| 指標 | 値 |
|:--|:--:|
| 2025年件数 | **20件** |
| ROI | **552.0%** |
| 収支 | +9,040円 |

**懸念**:
- サンプル数20件は統計的に少なすぎる
- ROI 552.0%は異常値の可能性
- 過学習リスク大

**必要な対応**:
- 6年間データで会場フィルターの妥当性を検証
- 20件で+9,040円 = 1件あたり+452円（大きすぎる）

## 4. 改善策の提案

### 提案1: A条件（A×A1×10-20）の即時削除 ★最優先

**理由**:
- 6年間ROI 89.0%（赤字）
- 2025年ROI 91.0%（赤字）
- 全年度で構造的に収益性が低い

**削除した場合の2025年収支**:
- 現在: +30,120円
- 削除後: +30,120 - (-7,150) = **+37,270円**（+7,150円改善）

**ただし**:
- オッズ帯10-12倍と14-16倍は黒字
- 以下の条件に限定すれば採用可能
  - **A×A1×10-12倍**: ROI 115.1%、+3,010円
  - **A×A1×14-16倍**: ROI 137.0%、+3,180円

**推奨**: オッズ帯を10-12倍と14-16倍に限定して復活

---

### 提案2: C条件の復活（会場フィルター付き）

**新条件**: C×20-30×B1 + 会場フィルター

| 年度 | ROI |
|:--:|:--:|
| 6年間合計 | **144.8%** |
| 2025年 | 73.3% |

**高ROI会場（6年間）**:
- 唐津、徳山、多摩川、平和島、津、丸亀、常滑、大村、若松、宮島

**リスク**:
- 2025年単年では赤字（ROI 73.3%）
- 年度ドリフトの可能性

**推奨**: 少額ペーパートレードで2025年12月データを追加検証

---

### 提案3: D条件の最適化

**現状**: D×30-60×A1/A2/B1（508件、ROI 136.2%、+18,390円）

**検証課題**:
- D×20-30を切り捨てた影響を6年間データで再検証
- D×40-50のみ、D×50-60のみの成績も確認

**仮説**: D×40-50が最も優秀な可能性

---

### 提案4: B×30-50×B1+会場フィルターの過学習チェック

**現状**: 20件、ROI 552.0%、+9,040円

**問題**: サンプル数20件は少なすぎる

**必要な検証**:
1. **6年間データでの検証**
   - 2020-2024年でも同じ会場フィルターが有効か
   - ROI 333.6%（6年間）は既に確認済み → **問題なし**

2. **会場別の内訳確認**
   - 10会場すべてで黒字か
   - 一部の会場が突出していないか

**推奨**: 6年間で安定性確認済みなら本格採用

---

### 提案5: 3点買いの全条件への拡大

**現状**: A×20-30 + 会場フィルター + 3点買いでROI 139.0%

**3点買いの効果**:
- A×20-30（1点）: ROI 62.5%
- A×20-30（3点）: ROI 78.8%
- **改善幅: +16.3pt**

**推奨**: 低オッズ帯（10-30倍）の全条件に3点買いを適用

## 8. 結論

### 今回の「改善」の本質

- **ROI向上は購入件数を減らした結果**
- **真の改善ではなく、選択と集中の結果**
- **購入機会の損失が大きい**

### 次のステップ

1. **A条件の即時削除** → **オッズ帯限定で復活**
2. **B条件の6年間検証** → **既に完了、本格採用**
3. **C条件の復活検討** → **ペーパートレードで検証**
4. **D条件の詳細分析** → **範囲最適化**
5. **3点買いの拡大** → **低オッズ帯全般に適用**

### 最終評価

**「改善した」とは言えない。「部分最適化に成功したが、全体最適化には至っていない」**
