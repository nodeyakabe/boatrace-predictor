🔍 発見された技術的課題
展示タイム重複加点の可能性
extended_scorer.py と beforeinfo_scorer.py で同じ展示タイム情報を2回加点している疑い
Phase 3で調査・修正予定
統合比率の固定化
現状: PRE:BEFORE = 0.6:0.4 固定
改善案: レース状況（天候、時間帯等）に応じて動的調整
プリセット値の根拠不明
多くの補正値が経験則で設定されており、最適化されていない
Phase 4の自動最適化で科学的根拠を確立
