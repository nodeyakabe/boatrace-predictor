# LINE Notify 設定ガイド

## 1. LINE Notifyトークンの取得（所要時間: 5分）

### 手順

1. **LINE Notify公式サイトにアクセス**
   - URL: https://notify-bot.line.me/ja/
   - 右上の「ログイン」をクリック

2. **LINEアカウントでログイン**
   - 普段使っているLINEアカウントでログイン

3. **トークン発行ページへ移動**
   - 右上のアカウント名をクリック
   - 「マイページ」を選択
   - 「トークンを発行する」ボタンをクリック

4. **トークン発行**
   - トークン名: `ボートレース予想通知`（任意の名前でOK）
   - 通知先: `1-on-1でLINE Notifyから通知を受け取る`
   - 「発行する」をクリック

5. **トークンをコピー**
   - 表示されたトークン（長い英数字の文字列）を**必ずコピー**
   - ⚠️ このトークンは一度しか表示されません
   - 例: `AbCdEfGh1234567890IjKlMnOpQrStUvWxYz`

6. **トークンを保存**
   - 次のステップで `.env` ファイルに貼り付けます

## 2. 動作確認

トークン発行後、LINE通知が届けば設定完了です。

### テストメッセージ送信方法

プロジェクトのセットアップ完了後、以下のコマンドでテスト通知を送信できます：

```bash
python scripts/automation/test_notification.py
```

成功すると、LINEに「🚤 ボートレース予想システム通知テスト」というメッセージが届きます。

## トラブルシューティング

### トークンが見つからない
- マイページの「連携中のサービス」から確認可能
- ただし、トークン文字列の再表示は不可
- 新しいトークンを発行し直してください

### 通知が届かない
1. LINEアプリで「LINE Notify」からのトークが作成されているか確認
2. トークンが正しく `.env` ファイルに設定されているか確認
3. トークンの前後に余分なスペースがないか確認

### トークンの削除・再発行
- マイページの「連携中のサービス」から「解除する」で削除可能
- 新しいトークンを発行し、`.env` ファイルを更新
