### 本日の最重要発見

**「精度改善 ≠ ROI改善」という逆説的な真実**

コース強制化検証の結果:

| 指標 | 強制化なし | 強制化あり | 変化 |
|------|-----------|-----------|------|
| 精度 | 49.8% | 55.4% | +5.6pt ✅ |
| ROI | **167.0%** | 116.0% | **-51pt ❌** |
| 収支 | **+166,860円** | +38,850円 | **-128,010円 ❌** |

**原因**: 非1コース予測は「低精度だが高オッズ」の穴狙い戦略として機能している。これを排除すると高配当機会を喪失する。

## 1. 優先度付き改善戦略リスト

### 【S評価】即時実行（ROI改善確実）

#### S-1. 非1コース予測の最適化（維持＆活用）

**現状**: 非1コース予測は精度25.7%だがROI貢献が大きい（穴狙い戦略）

**施策**:
- ❌ コース強制化は適用しない
- ✅ 非1コース予測の「質」を上げる（高オッズ×高期待値の条件を特定）
- ✅ 非1コース予測時のオッズ下限を上げる（30倍→40倍など）

**実装方法**:
```yaml
# config/prediction_strategy.yaml
non_course1_prediction:
  enabled: true  # 非1コース予測を維持
  min_odds: 40   # オッズ下限を引き上げ（高配当狙い）
  min_score_difference: 20  # スコア差が大きい場合のみ非1コース予測
```

**期待効果**: ROI +10-20pt（年間+30,000-60,000円）
**リスク**: 低（現状維持ベース）
**工数**: 0.5日

### 【A評価】1週間以内（ROI改善期待大）

#### A-1. 2着・3着予測精度向上（ROI影響度: 大）

**現状**:

| 指標 | 現状 | 目標 | 差分 |
|------|------|------|------|
| 2着精度 | 35.9% | 45% | -9pt |
| 3着精度 | 27.2% | 35% | -8pt |

**ROIへの影響分析**:
- 3連単的中率 = 1着的中 × 2着的中 × 3着的中（概算）
- 現状: 55.4% × 35.9% × 27.2% = 5.4%
- 目標: 55.4% × 45% × 35% = 8.7%
- **的中率 +3.3pt → ROI +50pt以上の可能性**

**施策**:
1. Stage2/Stage3モデルの再学習（条件付き確率を改善）
2. 1着予測を所与とした2着予測の精度向上
3. 着順間の相関を学習（例: 1-2着が同じ枠の確率）

**期待効果**: ROI +30-50pt
**リスク**: 中（モデル改修必要）
**工数**: 3-5日

#### A-3. オッズ連動型購入額調整

**現状**: 固定金額（300円）での購入

**施策**: 期待値（EV）に基づく購入額調整

```python
# 期待値ベースの購入額計算
def calculate_bet_amount(odds, predicted_prob, base_bet=300):
    ev = odds * predicted_prob
    if ev < 1.0:
        return 0  # 購入しない
    elif ev < 1.2:
        return base_bet * 0.5
    elif ev < 1.5:
        return base_bet
    else:
        return base_bet * min(ev, 2.0)  # 上限2倍
```

**期待効果**: ROI +10-15pt
**リスク**: 中（Kelly計算の精度に依存）
**工数**: 1日

## まとめ

本日の検証で最も重要な発見は**「精度とROIは別物」**ということです。

現在のシステムは:
- 全体精度51.3%（ベースライン56.9%より低い）
- しかしROI 167%（業界トップクラス）

この逆説的な成功の理由は「非1コース予測による高オッズ獲得」にあります。この資産を維持しつつ、2着・3着精度の向上でさらなるROI改善を目指すのが最適戦略です。
