## 8. 結論と推奨

### 意外な発見

1. **「荒れる会場 = 避けるべき」ではない**
   - まくり率最高の戸田がROI最高（624.9%）
   - 高オッズ帯（50-100倍）では荒れる会場の的中時リターンが大きい

2. **「堅い会場 = 安全」ではない**
   - 大村（まくり率最低）、芦屋もROI 0%
   - 堅い会場は本命決着が多く、高オッズ帯では的中しにくい

### 推奨戦略

#### オプション1: 件数削減重視
```
条件: まくり率<20% & 1C逃げ率>=60%
件数: 591→70（-88%）
ROI: 184%→280%
リスク: 年度安定性に課題
```

#### オプション2: 会場除外アプローチ
```
条件: ROI 0%会場（12会場）を除外
件数: 591→320（-46%）
ROI: 184%→341%
リスク: 過去実績ベース、将来は変動の可能性
```

#### オプション3: 現状維持
```
条件: B×50-100をそのまま維持
件数: 591
ROI: 184%（十分なプラス期待値）
リスク: 件数が多く資金効率が悪い
```

### 採用推奨

**オプション2（会場除外アプローチ）**を推奨
- 件数削減とROI向上のバランスが良い
- 年度安定性の課題が少ない
- シンプルで運用しやすい
