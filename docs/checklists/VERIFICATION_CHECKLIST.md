### コーディング

- [ ] **本番実装のコードを直接インポート**しているか
  ```python
  # 良い例
  from src.analysis.pattern_scorer import PatternScorer
  scorer = PatternScorer()
  result = scorer.calculate_scores(data)

  # 悪い例: 独自ロジックを書いている
  def my_calculate_scores(data):
      # 独自の計算ロジック（本番と異なる可能性）
  ```

- [ ] **独自の測定ロジックを書いていない**か
  - 特にスコア計算、ソート、予測判定などの核心部分

- [ ] **検証対象をコメントまたは出力で明示**しているか
  ```python
  print(f"検証対象: {'全レース' if all_races else '該当レースのみ'}")
  ```

### 出力確認

- [ ] **検証対象**（全レース vs 該当のみ）が出力に含まれているか
- [ ] **サンプル数**が出力されているか
- [ ] **ベースライン定義**が出力されているか
- [ ] **本番実装との整合性**（一致/不一致）が出力されているか

## クイックリファレンス

### 検証対象の違いによる影響

| 検証対象 | 意味 | 注意点 |
|---------|------|--------|
| 全レース | 本番実装と同じ条件 | 推奨 |
| 該当レースのみ | パターン該当レースのみ抽出 | 本番との乖離に注意 |

### 乖離が発生した場合のチェックポイント

1. 検証スクリプトは本番実装と同じロジックか？
2. 検証対象は本番と同じか？
3. ベースライン定義は正しいか？
4. サンプル選択にバイアスはないか？
