## 発見された法則性

### 年度間安定パターン（グレードS: 418件）

`data/validated_patterns.json` に469件のパターンを保存

#### 上位パターン例

| パターン | 6年間ROI | 安定年数 | スコア |
|:---------|:--------:|:--------:|:------:|
| 若松×D×A2 | 3909.4% | 5年 | 80点 |
| 徳山×D | 3319.9% | 6年 | 80点 |
| 児島×A×B1 | 2687.9% | 6年 | 80点 |
| 全会場×A×B1×モーター40%+ | 2070.4% | 6年 | **100点** |
| 全会場×D×A1×モーター40%+ | 1886.3% | 6年 | **100点** |
| 鳴門×C×A2 | 2002.6% | 6年 | **100点** |

### モーター条件の法則

| 条件 | 6年間ROI | 2025年ROI | 判定 |
|:-----|:--------:|:---------:|:----:|
| A×B1×モーター40%+ | 2044% | 196.6% | **採用** |
| A×A2×モーター40%+ | 1644% | 70.3% | 不採用 |
| D×A1×モーター40%+ | 1925% | 125.6% | 保留 |
| D×A2×モーター40%+ | - | 150.9% | 保留 |

**教訓**: 6年間データで高ROIでも、バックテスト（1-2-3全的中）で確認必須

### 非1コース予測の法則

| 予測コース | ROI | 収支貢献率 |
|:----------:|:---:|:----------:|
| 1コース | 131.7% | 28.5% |
| **非1コース** | **220.5%** | **71.5%** |
| 3コース | 351.1% | - |

**結論**: 非1コース予測が主要収益源。コース強制化は逆効果。

### オッズ帯別の法則

| オッズ帯 | 特徴 |
|:--------:|:-----|
| 10-20倍 | 信頼度Aでも赤字リスクあり（A×A1×10-20: ROI 89%） |
| 20-30倍 | 信頼度C×B1で有効（ROI 144.8%） |
| 30-50倍 | 信頼度B×B1+会場で最高効率（ROI 333.6%） |
| 40-50倍 | 信頼度D×B1で安定（ROI 198.1%） |
| 50-100倍 | 信頼度Bで有効（ROI 201.1%） |

## 条件追加時の採用基準

| 基準 | 条件 |
|------|------|
| ROI | バックテストで100%以上（黒字） |
| サンプル数 | 100件以上 |
| 年度安定性 | 直近4年で3年以上黒字 |
| 月別安定性 | 極端な偏りがないこと |
| 検証方法 | **必ずバックテスト**（1-2-3全的中）で判定 |
