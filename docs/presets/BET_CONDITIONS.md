## グローバルフィルター（全条件共通）

```python
GLOBAL_MONTH_EXCLUDES = [4]          # 4月除外（春の荒れレース）
GLOBAL_GRADE_EXCLUDES = ['SG']       # SG除外（A1選手集中でモデル非適用）
GLOBAL_ROOKIE_EXCLUDE = True          # ルーキーシリーズ除外
GLOBAL_WIND_FILTER = True             # 風速フィルター（会場別設定）
```

> 各条件の `month_excludes` で個別除外も可能（A_B1 は4月除外なし等）

## 採用基準（3段階検証フロー）

```
Tier 1: 簡易テスト（直近2年）
  合格基準: ROI 150%+ / 1/2年黒字 / サンプル50件+
    ↓
Tier 2: 標準テスト（6年間・unique）
  合格基準: ROI 100%+ / 4/6年黒字 / 累計収支プラス
    ↓
Tier 3: 実環境確認（BetTargetEvaluatorとの一致率95%+）
    ↓
採用決定 → config/bet_conditions.py に追加
```

詳細: [docs/guides/VALIDATION_WORKFLOW.md](../guides/VALIDATION_WORKFLOW.md)

## 不採用条件の参照先

[docs/improvement_attempts/REJECTED_IDEAS.md](../improvement_attempts/REJECTED_IDEAS.md)

主な不採用カテゴリ:
- 統計的判断不能（年間件数 <10件）
- 死に帯（特定オッズ帯で0的中が常態化）
- Tier1/Tier2 ROI基準未達
- 絶対利益が減少する絞り込み（ROIが高くても収益減）
- 市場効率により実装効果なし（会場×風向など）
