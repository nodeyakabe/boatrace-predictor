## 2. オッズが大幅に違っていた問題

### 問題報告
- 徳山8R: DB 24.1倍 → 実際 8.2倍（-15.9倍）
- 大村11R: DB 10.1倍 → 実際 7.5倍（-2.6倍）

### 調査結果
**結論**: ロジックの問題ではなく、**暫定オッズと確定オッズの正常な変動**

#### データ確認
```
徳山8Rのオッズ取得履歴:
- 2026-01-02 8R: 99通り, 取得=2026-01-23T14:51（確定オッズ）
- 2026-01-07 8R: 99通り, 取得=2026-01-23T15:33（確定オッズ）
...

大村11Rのオッズ取得履歴:
- 2026-01-08 11R: 99通り, 取得=2026-01-23T15:44（確定オッズ）
- 2026-01-15 11R: 99通り, 取得=2026-01-23T17:16（確定オッズ）
...
```

#### 原因の詳細
1. **以前のデータ（1月1日～22日）**:
   - 朝8:15に取得した**暫定オッズ**が格納されていた
   - レース開始12時間以上前のオッズ
   - 人気が集中すると大幅に下がる

2. **1月23日に実行したrefetch_jan_final_odds.py**:
   - 暫定オッズを**確定オッズ**で上書き
   - 投票締切時点の最終オッズ

3. **オッズ変動は正常**:
   - 徳山8R: 24.1倍 → 8.2倍は、12時間で人気が集中した結果
   - 大村11R: 10.1倍 → 7.5倍も同様

### ロジック検証
- オッズ取得スクリプト: ✅ 正常
- オッズ保存ロジック: ✅ 正常
- バックテスト計算: ✅ 正常

**問題なし** - 暫定と確定の時間差による正常な変動

## 3. ディスコード通知時のオッズ未取得問題

### 問題
- まれに「オッズ未取得」とDiscord通知される

### 原因特定

#### タイミング問題
```
旧スケジュール:
8:15 - オッズ取得開始
8:30 - 予想生成・Discord通知
       ↑
       わずか15分しかない
```

#### オッズ取得に必要な時間
- **通常**: 150レース × 0.5秒 = 75秒（1分15秒）
- **エラー発生時**: リトライ含めて90秒以上
- **サイト遅延時**: さらに延長

#### 問題のコード箇所
[scripts/automation/generate_daily_predictions.py:220](scripts/automation/generate_daily_predictions.py#L220)

```python
def _get_odds_data_for_eval(cursor, race_id: int, predictions: dict):
    combination = '-'.join(map(str, old_pred))
    cursor.execute("SELECT odds FROM trifecta_odds WHERE race_id = ? AND combination = ?",
                   (race_id, combination))
    row = cursor.fetchone()
    if row and row['odds']:
        return {combination: row['odds']}
    return None  # ← オッズ未取得の場合None（Discord通知でエラー）
```

### 対応
**新スケジュールで解決**:
```
新スケジュール:
7:30 - オッズ取得開始
8:00 - 予想生成・Discord通知
       ↑
       30分の余裕（2倍に拡大）
```

## 4. 新しいスケジュール

### 変更前
```
7:00 - 前日レース結果収集
7:05 - 前日確定オッズ取得
7:30 - 前日直前情報収集
7:45 - 前日直前予想生成
8:00 - 前日オリジナル展示データ収集
8:15 - 本日オッズ収集（暫定）
8:30 - 本日予想生成
```

**問題点**:
- 各処理間が5～15分で短すぎる
- オッズ取得→予想生成が15分しかない

### 変更後（最終版）
```
5:00 - 前日レース結果収集
5:30 - 前日確定オッズ取得（30分間隔）
6:10 - 前日直前情報収集（40分間隔）
6:50 - 前日直前予想生成（40分間隔）
7:10 - 前日オリジナル展示データ収集（20分間隔）
7:40 - 本日オッズ収集（30分間隔）
8:20 - 本日予想生成（40分間隔）★Discord通知
```

**改善点**:
- ✅ 各処理間に20～40分の余裕
- ✅ オッズ取得→予想生成が40分（従来の2.67倍に拡大）
- ✅ 早朝5:00開始で、8:20には全処理完了
- ✅ 前日データ収集を早朝に集中
- ✅ 本日予想生成を8:20に変更（ユーザー要望）

## 5. 2段階オッズ収集システム

### 目的
- **当日の予測生成**: 朝8:00に実行（ユーザーへの通知）
- **正確なバックテスト**: 確定オッズを使用

### 仕組み
1. **当日7:30**: 暫定オッズ取得
   - レース開始前のオッズ
   - 予測生成に使用

2. **翌朝5:15**: 確定オッズ取得
   - レース終了後の最終オッズ
   - 暫定オッズを上書き
   - バックテストで使用

### 効果
- ✅ 予測は当日朝に生成してDiscord通知
- ✅ バックテストは確定オッズで正確に検証
- ✅ 暫定と確定の乖離による誤差を解消
