## 5. 見直しの優先順位と実施計画

### 優先度S（最優先）- データ不足で不採用になった案

1. **A×50倍+等 信頼度条件**
   - 不採用理由: 分析時の計算ミス（1-2-3固定オッズで計算）
   - 見直し理由: **実装ミスの可能性、正しく再計算すべき**
   - 対象年度: 2020-2025全年
   - 実施内容: 正しいオッズ（予測順位ベース）で再バックテスト

2. **潮位補正（TideAdjuster）**
   - 現状: 7会場のみ対応、実装済みだが効果検証なし
   - 見直し理由: **データ充足率改善で検証精度向上**
   - 対象年度: 潮位データ取得可能期間
   - 実施内容: 潮位補正ON/OFF比較テスト

### 優先度A（高優先）- データ改善で精度向上が期待できる案

3. **motor_second_rate + venue_affinity**
   - 不採用理由: 2025年単年で-4.58pt悪化
   - 見直し理由: **データ充足率低年度で誤検証の可能性**
   - 対象年度: 2020-2025全年（6年間で再検証）
   - 実施内容: 年度別効果の確認、安定性評価

4. **会場別条件の拡張**
   - 現状: 一部会場のみフィルター適用
   - 見直し理由: **全会場データで会場特性を再分析**
   - 実施内容: 会場×信頼度×オッズ帯の網羅的分析

### 優先度B（中優先）- サンプル数増加で評価精度向上が期待できる案

5. **Bias Index（バイアス指数）再検証**
   - 不採用理由: 年度間で傾向逆転
   - 見直し理由: データ増加で安定性評価の精度向上
   - 実施内容: 6年間での傾向確認、会場別分析

6. **メタ指数フィルター**
   - 不採用理由: 仕様と実態の乖離
   - 見直し理由: データ充足で実態把握の精度向上
   - 実施内容: メタ指数の再定義と検証

7. **逃げ率・会場攻撃率のスコアリング再検証**
   - 不採用理由: 既存特徴量と重複
   - 見直し理由: データ充足で独自性の再評価
   - 実施内容: 特徴量重要度分析、交互作用の確認

### 優先度C（低優先）- 再検証の必要性が低い案

8. **モンテカルロシミュレーション**
   - 全指標悪化のため据え置き

9. **コース強制化**
   - -51pt大幅悪化のため据え置き

10. **選手調子係数**
    - -9.5pt悪化のため据え置き

## 7. 検証時の注意事項

### 計算ミス防止チェックリスト

- [ ] オッズは**予測順位ベース**で取得（1-2-3固定ではない）
- [ ] SQLのJOINが正しく予測と結びついている
- [ ] サンプル数が極端に少ない場合は条件を疑う
- [ ] 分析スクリプトとバックテストスクリプトで結果が乖離していないか確認

### 採用基準（再確認）

| 基準 | 条件 |
|------|------|
| ROI | 100%以上（黒字） |
| 黒字年数 | **4/6年以上** |
| サンプル数 | 100件以上（6年間合計） |
| 年度安定性 | 極端な偏りがないこと |

### データ品質の考慮

- 2021年・2023年は充足率17%以下 → 結果の信頼性に注意
- 2022年・2025年は充足率60%以上 → 信頼性高
- 潮位データは7会場のみ → 全会場適用は不可
