## 問題点と仮説

### 問題点

現在の購入条件は**2025年のレース傾向に最適化**されている可能性が高い。
2024年のデータでは異なる条件が最適だった可能性がある。

### 仮説

1. **オッズ帯の最適値が年度で異なる**
   - 2024年: より低いオッズ帯が有効？
   - 2025年: 30-50倍帯が有効

2. **信頼度別の最適条件が異なる**
   - 2024年: Dランクが優秀 → D条件を緩和すべき？
   - 2025年: Bランクが優秀

3. **級別条件の影響**
   - 2024年CランクROI 11.2%が異常に低い
   - B1級条件が2024年に合っていない可能性
