## 風向の定義

- **追い風**: 北, 北東, 北西（1コース有利方向）
- **向かい風**: 南, 南東, 南西（1コース不利方向）
- **横風**: 東, 西

## 風速帯の定義

- **0-2m**: 微風（wind_speed <= 2）
- **3-4m**: 弱風（2 < wind_speed <= 4）
- **5-6m**: 中風（4 < wind_speed <= 6）
- **7m+**: 強風（wind_speed > 6）

## 保留理由

1. 条件が不完全（さらなる深掘りが必要）
2. 風速×風向の組み合わせは複雑で、より詳細な分析が必要
3. レース番号帯による除外は単純すぎる可能性あり

## 今後の深掘り案

1. 会場別×風条件のクロス分析
2. 信頼度×レース番号×1コース級の3次元分析
3. 季節×風条件の相関確認
4. 連続的中/不的中パターンとの関連
