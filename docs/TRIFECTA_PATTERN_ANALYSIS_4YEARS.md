**作成日**: 2025-12-21

## エグゼクティブサマリー

### 分析目的
2025年のみROI +3.5%でプラス、2022-2024年はマイナスという状況を踏まえ、年度を跨いで安定した「的中しやすい条件」と「的中しにくい条件」を探索し、ベッティングフィルタ改善に活用可能な知見を抽出する。

### 主要発見

| カテゴリ | 発見事項 | 推奨アクション |
|---------|---------|--------------|
| 安定プラス | オッズ30-100倍 & 予測1着5コース | 穴狙いフィルタに追加 |
| 安定マイナス | オッズ10-30倍 & 予測1着3/4コース | ベット除外フィルタに追加 |
| 的中ゼロ | オッズ100倍以上 & 予測1着6コース | 絶対に避ける |
| 2025年特異 | オッズ100倍以上 & 予測1着2コース | 少額で試験運用 |

## 4. ベッティングフィルタへの改善提案

### 4.1 採用推奨（即時実装可）

#### ネガティブフィルタ（ベット除外条件）

```python
# filter_engine.py に追加
NEGATIVE_ODDS_PATTERNS = [
    # オッズ10-30倍 & 予測1着3/4コース → 安定してROI -40%前後
    {'odds_min': 10, 'odds_max': 30, 'pred_1st': [3, 4]},

    # オッズ100倍以上 & 予測1着6コース → 的中率ゼロ
    {'odds_min': 100, 'odds_max': float('inf'), 'pred_1st': [6]},
]
```

**期待効果**:
- 対象レース（約1,000レース/年）を除外
- 安定してマイナスのパターンを回避
- 推定ROI改善: +2~3pt

#### ポジティブフィルタ（穴狙い条件）

```python
# 通常除外されるレースでも条件を満たせばベット
UPSET_PATTERNS = [
    # オッズ30-100倍 & 予測1着5コース → 安定してROI +10%程度
    {'odds_min': 30, 'odds_max': 100, 'pred_1st': [5]},
]
```

**期待効果**:
- 少数だが高期待値のレースを拾う
- 推定ROI改善: +1~2pt

### 4.2 試験運用推奨（少額）

以下は2025年のみ好調のため、過学習リスクあり。少額で試験運用を推奨。

```python
# 試験運用パターン（feature_flagで制御）
EXPERIMENTAL_PATTERNS = [
    # オッズ100倍以上 & 予測1着2コース
    {'odds_min': 100, 'odds_max': float('inf'), 'pred_1st': [2]},

    # 1コースB1/B2 & 予測1着2コース
    {'c1_rank': ['B1', 'B2'], 'pred_1st': [2]},
]
```

### 4.3 会場別フィルタ強化

```python
# 荒れ会場（江戸川、戸田、平和島）では予測1着1コースを避ける
CHAOTIC_VENUE_FILTER = {
    'venues': ['03', '02', '04'],
    'exclude_pred_1st': [1],  # 予測1着1コースは的中率が低い
}

# 堅い会場（大村、徳山、宮島）では予測1着1コースを優先
SOLID_VENUE_FILTER = {
    'venues': ['24', '18', '17'],
    'prefer_pred_1st': [1],  # 予測1着1コースの信頼度が高い
}
```

## 7. 注意事項

1. **過学習リスク**: 2025年限定で好調なパターンは、たまたま当たっただけの可能性がある
2. **サンプル数**: 予測1着5/6コースはサンプル数が少なく、統計的信頼性が低い
3. **オッズ変動**: 実際のベット時にはオッズが変動する可能性がある
4. **データ期間**: 2023年のデータが少ない（9,075レース）ため、この期間の分析結果は参考程度
