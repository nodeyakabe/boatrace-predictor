## 詳細評価

### アプローチ3: ペアワイズ相対スコアリング

#### 概要

艇間の直接対決確率をモデル化し、相対的な強さから順位を予測するアプローチ。

#### 検証結果

| 項目 | 値 |
|------|-----|
| テスト期間 | 2025-11-28 〜 2025-12-10 |
| 対象レース | 482レース |
| 最適パラメータ | gamma=0.5 |
| モデルAUC | 0.7351（目標: 0.65以上） |

| 指標 | Baseline | Pairwise | 改善量 | 目標 | 判定 |
|------|----------|----------|--------|------|------|
| 1着的中率 | 30.5% | 45.2% | **+14.7pt** | - | OK |
| 2着的中率 | 20.3% | 27.6% | **+7.3pt** | +2.0pt | OK |
| 3着的中率 | 16.6% | 20.5% | **+3.9pt** | +2.0pt | OK |
| 3連単的中率 | 3.9% | 6.4% | **+2.5pt** | - | OK |
| ROI | 121.2% | 122.8% | **+1.7pt** | >=0pt | OK |
| 購入機会 | - | 100% | - | >=80% | OK |

#### 成功条件チェック

| 条件 | 結果 | 判定 |
|------|------|------|
| ROI >= baseline | 122.8% >= 121.2% | OK |
| 2着的中率 +2pt以上 | +7.3pt | OK |
| 3着的中率 +2pt以上 | +3.9pt | OK |
| 購入機会 80%以上 | 100% | OK |

**成功条件: 4/4 達成**

#### 検証結果の妥当性評価

##### 1. サンプルサイズの評価

| 項目 | 値 | 評価 |
|------|-----|------|
| 検証レース数 | 482レース | 統計的に十分 |
| 検証期間 | 13日間 | 複数週の傾向をカバー |
| 学習データ | 11,121レース | 汎化性能の裏付け |

**計算**: 2着的中率の改善（+7.3pt）の95%信頼区間
- 標準誤差: sqrt(0.276 * 0.724 / 482) ≒ 0.020
- 95%CI: 7.3pt ± 3.9pt → 3.4pt 〜 11.2pt
- 下限でも目標+2ptを上回る → **統計的に有意**

##### 2. 期間の評価

- 平日・休日を含む2週間弱
- 複数会場のデータを含む
- 季節変動の影響は限定的

##### 3. 潜在的リスク

| リスク | 可能性 | 対策 |
|--------|--------|------|
| モデルドリフト | 中 | 定期的な再学習、段階的展開 |
| 過学習 | 低 | 検証AUC 0.7351で汎化確認済み |
| 計算コスト | 低 | ペアワイズ計算は軽量 |

#### 採用判定

**採用推奨**

理由:
1. 全ての成功条件を達成
2. 統計的に有意な改善効果
3. 計算コストが低い
4. フラグによる簡単なON/OFF

### アプローチ5: モンテカルロシミュレーション

#### 概要

レース物理モデル（スタート、ターン、直線走行）をシミュレーションし、5000回の試行から確率分布を生成するアプローチ。

#### 検証結果

| 項目 | 値 |
|------|-----|
| テスト期間 | 2025-11-28 〜 2025-12-08 |
| 対象レース | 300レース |
| シミュレーション回数 | 5000回/レース |

| 指標 | Baseline | Monte Carlo | 改善量 | 判定 |
|------|----------|-------------|--------|------|
| 1着的中率 | 48.0% | 39.5% | **-8.5pt** | NG |
| 2着的中率 | 29.4% | 30.9% | +1.5pt | - |
| 3着的中率 | 21.0% | 18.5% | **-2.5pt** | NG |
| 3連単的中率 | 5.95% | 3.70% | **-2.25pt** | NG |
| 実行時間 | 929ms | 1337ms | **+407ms** | NG |

#### 不採用理由

1. **1着精度の大幅悪化（-8.5pt）**
   - 既存の予測精度を大きく毀損
   - 全体のROIに深刻な影響

2. **3着精度の悪化（-2.5pt）**
   - 改善を目指すべき指標が悪化
   - 2着の微改善（+1.5pt）では補えない

3. **計算コストの増大（+407ms）**
   - レースあたり44%の処理時間増加
   - 5000回のシミュレーションが重い

4. **物理モデルの限界**
   - ボートレースの複雑な要素をモデル化しきれない
   - 乱数ベースのシミュレーションは安定性に欠ける

#### 不採用判定

**不採用**

理由:
1. 主要指標（1着、3着、3連単）が全て悪化
2. 計算コストが大幅に増加
3. 物理モデルの精度向上には多大な開発工数が必要
