### 2. 市場効率性検証（Phase 1）

#### 2-1. 検証方法

```sql
-- 波高帯別の1号艇期待オッズ（trifecta_odds使用）
-- 1-X-X組み合わせの平均オッズで1号艇期待オッズを推定
SELECT
    CASE
        WHEN wave_height >= 10 THEN '10cm+（超高波）'
        WHEN wave_height >= 6 THEN '6-9cm（高波）'
        WHEN wave_height >= 3 THEN '3-5cm（中波）'
        WHEN wave_height >= 1 THEN '1-2cm（低波）'
        ELSE '0cm（無波）'
    END as wave_category,
    COUNT(*) as race_count,
    AVG(avg_pit1_odds) as avg_odds
FROM (SELECT race_id, AVG(odds) as avg_pit1_odds
      FROM trifecta_odds
      WHERE combination LIKE '1-%'
      GROUP BY race_id)
GROUP BY wave_category
```

#### 2-2. 検証結果（2020-2025年、238,220レース）

**波高帯別の1号艇オッズ:**

| 波高帯 | レース数 | 平均オッズ | 相対倍率 | 解釈 |
|:-------|:--------:|:----------:|:--------:|:-----|
| NULL | 18,805件 | 117.57倍 | 1.08x | データなし |
| 0cm（無波） | 19,209件 | 110.17倍 | 1.01x | 穏やか |
| **1-2cm（低波）** | **123,010件** | **109.05倍** | **1.00x** | **ベースライン** |
| 3-5cm（中波） | 82,869件 | 111.00倍 | 1.02x | やや高波 |
| 6-9cm（高波） | 8,554件 | 108.62倍 | 1.00x | 高波 |
| **10cm+（超高波）** | **4,116件** | **104.52倍** | **0.96x** | **ターゲット** |

**オッズ差の計算:**
- ベースライン（1-2cm低波）: 109.05倍
- 超高波高（10cm以上）: 104.52倍
- **オッズ差: (104.52 - 109.05) / 109.05 = -4.15%**

#### 2-3. 市場効率性の判定

**判定基準:**
- オッズ差≥+5% → 市場効率性: 低い（実装の価値あり）
- オッズ差≥+2% → 市場効率性: 中程度（慎重に実装検討）
- オッズ差<+2% → 市場効率性: 高い（実装不要）

**実績: -4.15%** < +2% → ❌ **市場効率性: 高い（実装不要）**

**解釈:**
- 高波高時でも1号艇オッズは**低下**している（-4.15%）
- 予想通りの動き: 高波高時は1コース不利 → 市場オッズが低下
- **波高情報は既に市場オッズに織り込まれている**
- TJ-10（潮位）と同様、効果なしの可能性が極めて高い

## ❌ 不採用の理由

**市場効率性検証結果:**

| 基準 | 要件 | 実績 | 判定 |

| **方向性** | 高騰 | **低下** | ❌ **逆方向** |

**解釈:**
- 高波高時に1号艇オッズが**低下**している（-4.15%）
- これは市場が波高情報を正しく織り込んでいる証拠
- 波高が高い → 1コース不利 → オッズ低下（予想通り）
- **波高フィルターを追加しても、ROI改善は見込めない**

## 📈 知見と教訓

### 教訓1: 公開情報は市場オッズに織り込まれる

**公開情報の例:**
- 気象データ（波高、風速、潮位）
- 選手データ（級別、勝率、F数）
- モーターデータ（2連率、3連率）

**市場効率性仮説:**
- 公開情報 → 市場参加者全員がアクセス可能
- 予想サイト、オッズ設定者が考慮済み
- **既にオッズに反映済み → ROI改善不可**

**検証済みの失敗事例:**
- TJ-10（潮位）: ROI±0.0pt
- TJ-6（波高）: オッズ差-4.15%（市場織り込み済み）

### 教訓2: データ品質と効果は無関係

**データ品質が良くても効果ゼロ:**

| 施策 | データ充足率 | データ品質 | 効果 |
|:-----|:----------:|:----------:|:----:|
| TJ-10（潮位） | 100%（7会場） | ★★★★★ | ROI±0.0pt ❌ |
| TJ-6（波高） | 99.45%（24会場） | ★★★★★ | オッズ差-4.15% ❌ |

**教訓**: データ品質ではなく、**市場効率性**が重要

### 教訓3: 市場効率性検証の重要性

**実装前の市場効率性検証が必須:**
1. 公開情報を使う施策は特に要注意
2. オッズ差≥+5%を確認
3. 閾値未達なら実装しない

**今回の成功:**
- TJ-6は実装前に市場効率性を検証
- オッズ差-4.15%判明 → 即座に不採用
- **TJ-10のような無駄な実装を回避**
