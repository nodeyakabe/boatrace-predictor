## 3. 統計的有意性検定（重要） 🔴

### Phase A-C: baseline vs edge_test

| 項目 | 値 |
|------|-----|
| Baseline ROI | 24.0% |
| edge_test ROI | 21.4% |
| **ROI差** | **-2.6%** |
| t統計量 | -3.114 |
| p値 | **0.0018** |
| 95%信頼区間 | [-4.2%, -1.0%] |
| Cohen's d | -0.026（効果サイズ: 小） |

**判定**: ❌ **統計的に有意な悪化** (p < 0.05)

→ **edge_testは採用すべきでない**

---

### Phase A-C: baseline vs venue_test

| 項目 | 値 |
|------|-----|
| Baseline ROI | 24.0% |
| venue_test ROI | 19.9% |
| **ROI差** | **-4.1%** |
| t統計量 | -4.910 |
| p値 | **0.0000** |
| 95%信頼区間 | [-5.7%, -2.5%] |
| Cohen's d | -0.041（効果サイズ: 小） |

**判定**: ❌ **統計的に有意な悪化** (p < 0.05)

→ **venue_testは採用すべきでない**

### 11月データのみでの検証（参考）

→ **長期データ（全期間）での判定が正しい**

## 7. 技術的知見

### 統計的有意性検定の重要性

**Phase A-Cの判定プロセス（問題あり）**:
1. 11月データでバックテスト実施
2. ROI低下を確認（24.0% → 21.4%）
3. **統計的有意性の確認なし**
4. 不採用決定

**改善後のプロセス（今回実装）**:
1. 全期間データでバックテスト実施
2. ROI低下を確認（24.0% → 21.4%）
3. **統計的有意性検定を実施** ← 重要
4. p値=0.0018 < 0.05 → 有意な悪化を確認
