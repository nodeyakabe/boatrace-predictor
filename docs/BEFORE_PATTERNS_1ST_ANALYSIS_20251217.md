## 🔍 ベースライン差-1.31ptの原因

### 結論: BEFORE_PATTERNS_1STは原因ではない

1. **全パターン適用時の効果**: +0.00pt
2. **ベースライン差**: -1.31pt（別の要因）

### 真の原因候補

1. **BEFORE_PATTERNS_2ND/3RD/TOP3の影響**
   - 2着/3着用パターン、TOP3パターンが1着予測精度を低下させている可能性

2. **パターン適用順序の問題**
   - 複数パターンが重複適用される際の倍率計算が不適切

3. **比較対象のベースラインの定義違い**
   - 前回の検証と今回の検証で、ベースラインの定義が異なる可能性

## 💡 推奨アクション

### アクション1: ポジティブ/ネガティブの分離処理 🔴 最優先

**問題**:
- ポジティブパターンで+3.06pt改善
- ネガティブパターンで-13.09pt悪化
- 両方適用で相殺（+0.00pt）

**解決策**:
```python
# 現状の処理（掛け算）
score = base_score * positive_multiplier * negative_multiplier

# 提案: 分離処理
if has_negative_pattern:
    score = base_score * negative_multiplier  # ネガティブのみ適用
elif has_positive_pattern:
    score = base_score * positive_multiplier  # ポジティブのみ適用
```

**期待効果**: +1.5～3.0pt改善

---

### アクション2: ネガティブパターンの閾値緩和 ⚠️ 要検証
