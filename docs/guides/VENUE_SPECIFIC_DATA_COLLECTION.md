```sql
-- 潮汐データ
CREATE TABLE tide_data (
    venue_code TEXT,
    race_date TEXT,
    tide_time TEXT,
    tide_type TEXT,  -- '満潮' or '干潮'
    tide_level_cm REAL
);

-- 気象データ
CREATE TABLE venue_weather_data (
    venue_code TEXT,
    race_date TEXT,
    wind_speed REAL,
    wind_direction TEXT,
    temperature REAL,
    water_temperature REAL,
    weather TEXT,
    wave_height REAL
);

-- 前検タイム
CREATE TABLE zenken_time_data (
    venue_code TEXT,
    race_date TEXT,
    racer_id INTEGER,
    pit INTEGER,
    zenken_time REAL,
    motor_no INTEGER
);

-- 進入コース別成績
CREATE TABLE course_statistics (
    venue_code TEXT,
    year INTEGER,
    month INTEGER,
    course INTEGER,
    win_rate REAL,
    place_rate_2 REAL,
    place_rate_3 REAL,
    samples INTEGER
);
```

## 使用方法

### ステップ1: データ収集（CSV出力）

```bash
# 潮汐表のみ収集（海水面競艇場のみ対象）
python scripts/data_collection/fetch_venue_specific_data.py \
  --start 2024-01-01 \
  --end 2024-12-31 \
  --output data/csv/venue_specific_2024 \
  --types tide

# 全データタイプを収集
python scripts/data_collection/fetch_venue_specific_data.py \
  --start 2024-01-01 \
  --end 2024-12-31 \
  --output data/csv/venue_specific_2024 \
  --types tide,weather,zenken,course

# 特定の競艇場のみ収集（例: 丸亀、児島）
python scripts/data_collection/fetch_venue_specific_data.py \
  --start 2024-01-01 \
  --end 2024-12-31 \
  --output data/csv/venue_specific_2024 \
  --types tide,weather,zenken,course \
  --venues 15,16
```

**出力ファイル**:
- `tide_data.csv` - 潮汐データ
- `weather_data.csv` - 気象データ
- `zenken_time.csv` - 前検タイムランキング
- `course_stats.csv` - 進入コース別成績

### ステップ2: DB投入（検証モード）

```bash
# 検証のみ（実際には投入しない）
python scripts/maintenance/import_venue_specific_data.py \
  --input data/csv/venue_specific_2024 \
  --dry-run
```

### ステップ3: DB投入（本番）

```bash
# 本番投入
python scripts/maintenance/import_venue_specific_data.py \
  --input data/csv/venue_specific_2024
```

### スクレイピング時の注意点

- robots.txtの確認

- 動画: リプレイ → 現時点では対象外

- リアルタイム: 気象データ（レース当日のみ）
- 日次: 出走表、展望、前検タイム
- 開催期間: モーターランキング、選手成績
