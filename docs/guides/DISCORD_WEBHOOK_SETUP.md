# Discord Webhook 設定ガイド

## 1. Discord Webhook URLの取得（所要時間: 5分）

### 前提条件

- Discordアカウントを持っている
- 通知を受け取るサーバー（またはサーバー作成権限）がある

### 手順

#### ステップ1: Discordサーバーを用意

既存のサーバーを使うか、新しいサーバーを作成します。

**新しいサーバーを作る場合:**
1. Discordを開く
2. 左サイドバーの「+」ボタンをクリック
3. 「サーバーを作成」を選択
4. サーバー名を入力（例: `ボートレース予想`）
5. 作成完了

#### ステップ2: 通知用チャンネルを作成（推奨）

専用チャンネルを作成すると通知が整理されます。

1. サーバー内で右クリック → 「チャンネルを作成」
2. チャンネル名を入力（例: `🚤レース通知`）
3. タイプ: テキストチャンネル
4. 作成

#### ステップ3: Webhook URLを取得

1. 通知を送りたいチャンネルの右側にある⚙️（設定アイコン）をクリック
2. 左メニューから「連携サービス」を選択
3. 「ウェブフック」タブを選択
4. 「新しいウェブフック」をクリック
5. ウェブフック名を設定（例: `ボートレース予想Bot`）
6. 「ウェブフックURLをコピー」をクリック

**重要: このURLは絶対に他人に教えないでください！**

URLの形式: `https://discord.com/api/webhooks/123456789/abcdefg...`

#### ステップ4: URLを保存

次のステップで `.env` ファイルに貼り付けます。

## 2. 動作確認

Webhook設定後、以下のコマンドでテスト通知を送信できます：

```bash
python scripts/automation/test_notification.py
```

成功すると、Discordチャンネルに「🚤 ボートレース予想システム通知テスト」というメッセージが届きます。

## トラブルシューティング

### Webhook URLが見つからない

**サーバーの管理権限がない場合:**
- サーバー管理者に連携サービスの権限を付与してもらう
- または自分のサーバーを作成する

### 通知が届かない

**原因1: URLが間違っている**
- URLをもう一度コピー＆ペーストしてみる
- 余分なスペースがないか確認

**原因2: Webhookが削除された**
- Discord設定画面で「連携サービス」→「ウェブフック」を確認
- Webhookが存在しない場合は再作成

**原因3: チャンネルの通知設定**
- Discordアプリの通知設定を確認
- チャンネルがミュートされていないか確認

### Webhookの削除・再作成

1. Discord設定画面で「連携サービス」→「ウェブフック」
2. 該当のWebhookの右側にある「削除」をクリック
3. 新しいWebhookを作成
4. `.env` ファイルを更新

## セキュリティに関する注意

### Webhook URLの取り扱い

⚠️ **Webhook URLは秘密情報です**

- GitHubなどに公開しない（`.env`ファイルは`.gitignore`に含まれています）
- 他人に教えない
- スクリーンショットを共有する際は隠す

**理由:** URLを知っている人は誰でもあなたのDiscordチャンネルにメッセージを送信できます

### URLが漏洩した場合

1. 直ちにWebhookを削除
2. 新しいWebhookを作成
3. `.env`ファイルを更新

## Discord Webhookの利点

✅ **設定が簡単** - 5分で完了
✅ **完全無料** - 料金なし
✅ **プッシュ通知** - スマホアプリで即座に受信
✅ **リッチフォーマット** - 太字、コードブロックなど使用可能
✅ **ログ保存** - 過去の通知を遡って確認可能
✅ **複数デバイス** - PC・スマホ両方で確認可能

## よくある質問

### Q1: 個人用のDMに通知を送れますか？

いいえ、Webhookはサーバーのチャンネル専用です。
個人専用の通知が欲しい場合:
1. 自分だけのサーバーを作成
2. そこにWebhookを設定

### Q2: 複数のチャンネルに通知できますか？

はい。チャンネルごとにWebhook URLを取得し、環境変数を複数設定すれば可能です。
（実装のカスタマイズが必要）

### Q3: 通知の音を変更できますか？

Discord側の設定で通知音をカスタマイズできます:
- サーバー設定 → 通知設定 → 通知音

### Q4: 過去の通知を削除できますか？

はい。Discordチャンネル内でメッセージを個別に削除できます。
一括削除する場合はBotの追加機能が必要です。

### Q5: Webhookを誤って削除してしまった

問題ありません。新しいWebhookを作成し、`.env`ファイルを更新すればOKです。
