# 購入条件テストガイド

**作成日**: 2025-12-24
**目的**: 購入条件変更時の標準テスト手順を定義

---

## 標準テストスクリプト

```bash
python scripts/backtest/standard_backtest.py
```

### オプション

| オプション | 説明 |
|-----------|------|
| `--year 2024` | 対象年度を指定（デフォルト: 2025） |
| `--save-baseline` | 結果をベースラインとして保存 |
| `--compare` | 前回ベースラインと比較 |

---

## 標準ワークフロー

### 1. 変更前のベースライン保存

```bash
python scripts/backtest/standard_backtest.py --save-baseline
```

結果は `data/backtest_baseline.json` に保存されます。

### 2. コード変更

`src/betting/bet_target_evaluator.py` の購入条件を変更します。

**変更時の注意点**:
- `BET_CONDITIONS` または `AB_RANK_SPECIAL_CONDITIONS` を編集
- `standard_backtest.py` の `CONDITIONS` リストも同期すること

### 3. 変更後のテスト実行

```bash
python scripts/backtest/standard_backtest.py --compare
```

ベースラインとの差分が表示されます。

### 4. 結果の判断基準

| 指標 | 合格基準 |
|------|---------|
| ROI | 100%以上（黒字） |
| ROI変動 | ±10pt以内が望ましい |
| 件数変動 | ±20%以内が望ましい |

## 複数年度テスト

年度間安定性を確認するには:

```bash
# 各年度でテスト
python scripts/backtest/standard_backtest.py --year 2020
python scripts/backtest/standard_backtest.py --year 2021
python scripts/backtest/standard_backtest.py --year 2022
python scripts/backtest/standard_backtest.py --year 2023
python scripts/backtest/standard_backtest.py --year 2024
python scripts/backtest/standard_backtest.py --year 2025
```

**安定性基準**:
- 6年中5年以上で黒字
- 年度間ROI変動が±30pt以内
