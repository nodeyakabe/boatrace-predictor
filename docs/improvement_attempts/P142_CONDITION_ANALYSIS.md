## 上位AIレビュー（2026-04-17・採用判断）

### 採用根拠（強い順）

1. **F1の因果メカニズム実証**: スコア80-90では教科書展開率9.7%（90+の11.7%より低い）→ p4が2着に入る余地が存在。因果チェーンが定量的に確認されている。

2. **F3の両期間一貫性**: 300倍超は IS/OOS 両方で0的中。単年ノイズでなく構造的な特性。

3. **OOS改善（IS < OOS）**: IS 143.6% → OOS 230.4%。過学習の正反対の構造。

4. **ポートフォリオ増加**: +104,540円 / 6/6年黒字維持（ROI-12.6ptは許容範囲）。

### リスク・注意事項

- **高分散**: 年あたりの的中数は約3〜5件。2年連続不振の確率は低くない。
- **現実的な期待ROI**: ノイズを除いた真の期待値は **120〜150%程度**。187%は過去良年を含む上振れ。
- **F2（11月除外）の統計的弱さ**: 将来サンプルが蓄積すれば再評価が必要。
