## 1. 調査の背景と目的

### 現行システムの複数点購入

現行では `B_A1_30_50_8VENUES` のみがパターンH（2点買い）を採用している:
- メイン: p1-p2-p3（1着予測1位・2着予測2位・3着予測3位）200円
- サブ: p1-p2-p4（1着予測1位・2着予測2位・3着予測4位）100円

### ユーザーの疑問（調査の出発点）

> 「同じ条件の同じオッズの複数のレースを購入するよりも、一つのレースを複数点買いした方が的中率が上がって利益が出るのでは？」

この疑問を5段階で徹底検証した。

## 8. 総括

### 全フェーズの結論

| フェーズ | 検証内容 | 結論 |
|:---:|:---|:---|
| Phase 1 | advance_before_matchフィルター | 除外率60-82%で黒字年崩壊 → 全不採用 |
| Phase 2 | サブ買い目（ROIベース） | ROI希薄化 → 全不採用（評価基準が不完全） |
| Phase 3 | 絶対収支ベース再検討 | C_P132+p142・D_P143+p145が採用候補に浮上 |
| Phase 4 | サブ単独ROI・大サンプル・Opus判定 | 大サンプルでROI78.9%/53.1%（採算割れ確認） |
| Phase 5 | 180組み合わせ全スキャン | 実購入後ROI100%超のサブは存在しない |

### なぜ複数点買いが機能しないか（完全な答え）

**現行パターンH（B_A1 + p1p2p3+p1p2p4）が機能する理由（例外）**:
- 30-50倍帯という特殊条件下で、p1→1着・p2→2着のオーソドックスな流れが高確率で起きる
- サブ（p1p2p4）も同じ「1着p1・2着p2」の流れに乗っており、3着だけp4に変わる合理的な変形
- 大サンプルROI 79.8%でも、30-50倍フィルター後は287.7%に跳ね上がる特殊帯域

**他の条件でサブ買い目が機能しない理由**:
1. **穴狙い200倍超帯**: p1が1着になること自体が希少イベント。その上で「特定のp4が2着」というサブは独立した稀少イベントの積。大サンプルROI: p1p4p2=78.9%・p1p4p5=53.1%
2. **オッズフィルターの罠**: 大サンプルROI>100%でも、実際のオッズフィルター後は採算割れになる。フィルターが「サブが特に当たりにくい帯域」を選んでいるから
3. **統計的サンプル不足**: 「最低50的中（2,500-5,000件）が必要」という原則に対して、実購入後の的中は3〜17件程度。1件の的中/未的中で年度収支が反転するノイズ領域

### 再検討の条件

サブ買い目を再度検討するには:
- **サブ単独で50件以上の的中が必要** = 約5,000-10,000件の実購入レースが必要
- 現在の購入規模（年平均約727件）では、単一条件のサブで50的中に達するには約7-14年かかる
- 現実的な再検討タイミング: **ポートフォリオを大幅拡張して年間件数が現在の数倍になった場合のみ**

1. **同方向exacta**: 高ROIは三連単との相関（Scenario A）によるもの。真の保険価値（Scenario B純損益）は大幅マイナス
2. **排反exacta（C_P132 p1-p2・D_P143 p1-p3）**: 保険として機能するが純損益は赤字
3. **B_A1 exacta p1-p2**: +9,710円の正体はScenario A（Pattern Hのp124と完全重複）。真の保険値-1,380円
4. **データ信頼性**: payoutsは「的中した組み合わせの払戻」のみ収録 + exacta未発売レースがあり、Bシナリオを過小評価している可能性あり

### 総括（Phase 6-8）

展開カバー型設計・2連単保険とも全不採用。

**戦略1（展開カバー）が機能しない核心的理由:**
- スコア差分布から見ると「カバーの必要性」はある（C_P132 p2/p3は差1.9pt、D_P143 p3/p4は差2.1pt）
- しかしオッズフィルター後の実購入サブセットでは、追加点数の投資増加を上回る払戻増加が得られない
- 現行条件が既に「最もROIの高い1点」に最適化されており、追加は全て価値希薄化を生む

**戦略2（2連単保険）が機能しない核心的理由:**
- 「同方向」保険: 三連単と同時的中する相関効果であって保険ではない
- 「排反方向」保険: 真の保険だが純損益赤字（市場が適正に価格付けしている）
- 単勝保険: B_A1でROI 101%（ほぼ損益ゼロ）だが、C_P132・D_P143では赤字

**例外（現行パターンH）が成立する理由（再確認）:**
B_A1の30-50倍帯でのp123+p124は「3着がp3かp4か」という同等確率の2択ヘッジ。スコア差分布でもp3/p4は78.8%が10pt以内で真に拮抗している。この特殊構造が他条件には存在しない。

### オッズ帯整合性[IV]の発見

Phase 9のスキャンで判明した重要な構造的制約:

```
30-70x帯条件 + 隣接rankスワップ:
  p123(35x) → p124 = 30-50x帯に入りやすい（in-range 17-32%）
  → Pattern H成立の必要条件を満たしやすい

100x以上帯条件 + 任意スワップ:
  p132(200x) → p142 = 250-350x（大幅に帯域外）
  p143(200x) → p142 = 150-200x（低すぎる）
  in-range率: ほとんど <15%
  → 条件[IV]が機能しない（オッズ帯の壁）
```

**結論**: 100倍超帯の穴狙い条件ではPattern Hは構造的に成立しない。
