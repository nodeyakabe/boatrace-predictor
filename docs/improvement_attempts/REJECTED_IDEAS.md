## 詳細

### 1. モンテカルロシミュレーション

| 項目 | 内容 |
|------|------|
| **施策ID** | `monte_carlo_simulation` |
| **カテゴリ** | simulation_based_prediction |
| **検証日** | 2025-12-19 |
| **判定** | **不採用** |

#### 概要

レース物理モデルをシミュレーションし、5000回の試行から確率分布を生成。

#### 検証結果

| 指標 | ベースライン | モンテカルロ | 差分 |
|------|:-----------:|:------------:|:----:|
| 1着的中率 | 48.0% | 39.5% | **-8.5pt** |
| 3着的中率 | 21.0% | 18.5% | **-2.5pt** |
| 計算時間 | 929ms | 1337ms | **+44%** |

#### 不採用理由

1. **主要指標全て悪化**: 1着-8.5pt、3着-2.5pt
2. **計算コスト増大**: +44%
3. **物理モデルの限界**: ボートレースの複雑性をモデル化困難

#### 教訓

- 物理シミュレーションは複雑なスポーツには不向き
- 既存モデルを希釈するリスク
- 早期検証（300レース）で問題発見できた

**詳細**: [monte_carlo_rejection_20251219.md](monte_carlo_rejection_20251219.md)

### 2. rank23オッズ校正

| 項目 | 内容 |
|------|------|
| **施策ID** | `rank23_odds_calibration` |
| **カテゴリ** | odds_integration |
| **検証日** | 2025-12-18 |
| **判定** | **不採用** |

#### 概要

2着・3着予測にオッズ情報を統合し、市場確率とMLモデル確率を組み合わせ。

#### 検証結果

| データ | 効果 |
|--------|:----:|
| 2024年（49件） | +2.04pt |
| 2025年（100件） | **±0.00pt** |

#### 不採用理由

1. **モデルドリフト**: 2024年で有効だったが2025年で効果消失
2. **市場環境変化**: 2着・3着ベッティング市場の効率化

#### 教訓

- **年度別検証必須**: 過去データだけで判断しない
- 市場環境は変動する
- 導入後も定期的な効果測定が必要

**詳細**: [rank23_odds_calibration_rejection_20251218.md](rank23_odds_calibration_rejection_20251218.md)

### 3. 選手調子係数（condition_factor）

| 項目 | 内容 |
|------|------|
| **施策ID** | `condition_factor` |
| **カテゴリ** | スコアリング |
| **検証日** | 2025-12-20 |
| **判定** | **不採用** |

#### 概要

直近20走の着順平均から調子係数（0.8〜1.2）を算出し、級別スコアに乗算。

#### 検証結果

| 方式 | 的中率 |
|------|:------:|
| ベースライン（級別のみ） | 42.90% |
| 調子係数適用 | **33.40%** |
| **差分** | **-9.50pt** |

#### 不採用理由

1. **精度悪化**: -9.5pt
2. **1着選手の約50%が「普通」トレンド**: 調子だけでは勝敗予測困難
3. **級別スコア単独の方が安定**

#### 教訓

- 直感的に良さそうな特徴量でも検証必須
- 既存の安定した指標を崩すリスク

### 4. 前付け常習者フィルター（forward_mover_filter）

| 項目 | 内容 |
|------|------|
| **施策ID** | `forward_mover_filter` |
| **カテゴリ** | フィルター |
| **検証日** | 2025-12-20 |
| **判定** | **不採用** |

#### 概要

前付け常習者がいるレースを購入対象から除外。

#### 検証結果

| 設定 | 購入数 | ROI | 収支 |
|------|:------:|:---:|:----:|
| フィルターOFF | 1,105 | 136.0% | +119,220円 |
| フィルターON | 983 | 128.4% | +83,580円 |
| **差分** | -122 | **-7.6pt** | **-35,640円** |

#### 不採用理由

1. **ab_rank ON状態で逆効果**: 高収益のA・Bランクレースまで除外
2. **前付けなし時は+3.9pt有効**だが、現設定では悪影響

#### 教訓

- 施策間の**依存関係**に注意
- 単独で有効でも、他の設定との組み合わせで逆効果になる

| 項目 | 内容 |

| **カテゴリ** | 購入条件 |

#### 概要

### 7. コース強制化

| 項目 | 内容 |
|------|------|
| **施策ID** | - |
| **カテゴリ** | 予測手法 |
| **検証日** | 2025-12-16 |
| **判定** | **不採用** |

#### 概要

スコア差が小さい場合、1コース以外の予測を1コースに強制変更。

#### 検証結果

| 指標 | 強制化なし | 強制化あり | 差分 |
|------|:---------:|:---------:|:----:|
| 精度 | 49.8% | 55.4% | +5.6pt |
| ROI | 167.0% | 116.0% | **-51pt** |
| 収支 | +166,860円 | +38,850円 | **-128,010円** |

#### 不採用理由

1. **精度は改善するがROIは大幅悪化**
2. **非1コース予測が全体収支の71.5%を稼いでいた**
3. 高オッズの穴狙い機会を失う

#### 教訓

- **精度改善 ≠ ROI改善**
- 収益源の分析が重要

## 共通の教訓

### 検証プロセス

1. **サンプル数**: 100件以上で検証
2. **年度別検証**: 過去データだけで判断しない
3. **バックテスト必須**: 6年間データ分析は参考値

### 施策設計

1. **既存施策との依存関係**: 単独で有効でも組み合わせで逆効果になる
2. **精度 ≠ ROI**: 精度改善がROI悪化を招くことがある
3. **過学習リスク**: 高ROIでも年度間安定性を確認

### 実装

1. **機能フラグ設計**: 安全なON/OFFが可能な設計
2. **コードパス確認**: 実装と統合は別問題
3. **早期検証**: 大規模実装前に小規模テスト
