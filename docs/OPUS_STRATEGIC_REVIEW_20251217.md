## 📐 統計的有意性の評価

### 計算結果

13,000レースでの標準誤差（SE）:

```
p = 0.52（的中率）
n = 13,000（サンプル数）
SE = sqrt(p * (1-p) / n) = sqrt(0.52 * 0.48 / 13000)
SE ≒ 0.0044 = 0.44%
```

**95%信頼区間**: ±1.96 * 0.44% = ±0.86%

### 各差分の有意性

| 差分 | 統計的有意性 | 評価 |
|------|-------------|------|
| ±0.54pt | **有意ではない** | 信頼区間内、追求不要 |
| ±0.77pt | **境界線上** | やや有意、無効化OK |
| ±1.31pt | **有意** | 信頼区間外、重要 |
| ±3.06pt | **高度に有意** | 極めて重要 |
| ±13.09pt | **極めて有意** | 最重要 |

**結論**:
- -0.54ptは統計的に有意ではなく、追求する価値が低い ✅
- -0.77ptは境界線上だが、無効化しても大きなリスクはない ✅
- ポジティブ/ネガティブの分離処理は高度に有意な効果が期待できる ✅
