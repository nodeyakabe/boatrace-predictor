## 1. 不採用案の再評価（優先度順）

### 超高優先度（計算ミス疑惑案件）

#### RJ-1. A×50倍+等 信頼度条件【最優先】

| 項目 | 内容 |
|------|------|
| **案件ID** | `confidence_high_odds_conditions` |
| **検証日** | 2026-01-13 |
| **不採用理由** | 分析時の計算ミス（1-2-3固定オッズで計算） |
| **再検証優先度** | **超高** |

**不採用時の状況**:
- 分析結果: A×50倍+ ROI 396%、6/6年黒字（明らかに異常値）
- 実テスト結果: ROI 58.4%、-21,130円
- 乖離原因: オッズ取得時のJOINが「1-2-3固定」で計算

**再検証理由**:
1. 計算ミスが確認されたが、**正しいオッズでの完全再計算は未実施**
2. 2021年・2023年のデータ欠損が検証結果に影響した可能性
3. 高オッズ帯（50倍+）は少数サンプルで判定されるため、データ欠損の影響大

**期待効果**: 新規高ROI条件発見の可能性（ROI +20-50pt）

**実施工数**: 2-3時間（分析スクリプト修正・再実行）

**実施手順**:
```bash
# 正しいオッズ計算で再分析
python scripts/analysis/analyze_high_odds_conditions.py --min-odds 50 --correct-odds

# standard_backtest.pyで検証
python scripts/backtest/standard_backtest.py --full
```
