## 1. 予測ロジックの構造

### 1.1 全体フロー

```
[入力]
  ├── 選手情報（成績、ランク、F/L数）
  ├── モーター情報（勝率、2連率）
  ├── コース情報（会場別勝率）
  └── 直前情報（展示タイム、ST、進入）

[スコアリング]
  ├── コース×ランクスコア（動的重み調整）
  ├── 選手スコア（直近成績重視）
  ├── モータースコア
  ├── 決まり手適性スコア
  ├── グレード適性スコア
  ├── 拡張スコア（ST、展示、チルト等）
  └── 複合条件バフ

[統合]
  TOTAL_SCORE = Σ(各スコア) → 0-100に正規化
  信頼度 = f(TOTAL_SCORE, データ充実度)

[出力]
  予測順位（1-6位）+ 信頼度（A-E）
```

### 1.2 重み設定（デフォルト）

| 項目 | 重み | 備考 |
|------|------|------|
| コーススコア | 動的 | 会場・グレード・データ充実度で調整 |
| 選手スコア | 動的 | 同上 |
| モータースコア | 動的 | 同上 |
| 決まり手適性 | 5点 | 過去180日のデータ |
| グレード適性 | 5点 | 過去365日のデータ |
| 拡張スコア | 20点 | ST、展示、チルト等 |
| 複合条件バフ | ±15点 | 特殊条件で加減点 |

### 1.3 信頼度の決定ロジック

```python
# スコアベースの判定
if total_score >= 75:
    confidence = 'A'
elif total_score >= 65:
    confidence = 'B'
elif total_score >= 55:
    confidence = 'C'
elif total_score >= 45:
    confidence = 'D'
else:
    confidence = 'E'

# データ充実度による制限
if data_quality >= 80:
    max_confidence = 'A'
elif data_quality >= 60:
    max_confidence = 'B'
elif data_quality >= 40:
    max_confidence = 'C'
elif data_quality >= 20:
    max_confidence = 'D'
else:
    max_confidence = 'E'

# 最終信頼度 = min(スコアベース, データ上限)
```

## 2. 信頼度別の予測精度

### 2.1 精度実績（2025年全期間）

| 信頼度 | レース数 | 1着的中率 | 2着的中率 | 3着的中率 | 3連単一致率 |
|--------|----------|-----------|-----------|-----------|-------------|
| **A** | 44 | **81.82%** | 18.18% | 25.00% | 9.09% |
| **B** | 1,430 | **71.05%** | 28.18% | 22.24% | 9.02% |
| **C** | 9,400 | **54.62%** | 23.76% | 20.66% | 5.96% |
| **D** | 4,783 | **37.63%** | 21.87% | 18.67% | 3.74% |
| **E** | 212 | **37.26%** | 21.23% | 17.45% | 4.25% |

### 2.2 評価

**良い点**:
- 信頼度と1着的中率に明確な相関（A: 81.8% → D: 37.6%）
- 信頼度A・Bの1着予測精度は高い

**問題点**:
- **2着予測の精度が低い**（18-28%で大きな差がない）
- **3着予測も同様**（17-25%で差が小さい）
- **3連単一致率が全体的に低い**（最大9.09%）
- 信頼度Eの3連単一致率が信頼度Dより高い異常（4.25% > 3.74%）

---

## 3. 問題点の分析

### 3.1 2着・3着予測の精度が低い理由

1. **単一スコアでの順位付け**
   - 全艇を同じスコアで評価し、上位から1-2-3位を決定
   - 「1着になりやすい艇」と「2着になりやすい艇」の特性が異なる可能性

2. **条件付き確率の未活用**
   - 「1着がAのとき、2着はB」という条件付き確率を考慮していない
   - 決まり手（逃げ/差し/まくり）による2着パターンの違いを十分に活用していない

3. **コース別の2着・3着特性**
   - 1コースが1着の場合、2着は2-3コースが多い
   - 1コースが崩れた場合、2着パターンが大きく変わる
   - これらの条件分岐が不十分

### 3.2 3連単的中率が低い理由

```
3連単的中率 = 1着的中率 × 2着的中率(条件付き) × 3着的中率(条件付き)

信頼度C の例:
  1着的中率: 54.62%
  2着的中率: 23.76%（独立の場合の期待値: 20%）
  3着的中率: 20.66%（独立の場合の期待値: 25%）

  独立仮定の3連単期待値: 54.62% × 20% × 25% = 2.73%
  実際の3連単一致率: 5.96%（期待値の2.2倍）
```

- 期待値よりは高いが、それでも**5.96%は低い**
- 2着・3着予測の精度向上が3連単的中率向上の鍵

### 3.3 信頼度Eの異常

| 信頼度 | 3連単一致率 | レース数 |
|--------|-------------|----------|
| D | 3.74% | 4,783 |
| E | **4.25%** | 212 |

- サンプル数の差（4,783 vs 212）による統計的揺らぎの可能性
- または、信頼度Eの特殊な条件（極端なオッズ帯など）が影響

## 5. 改善提案

### 5.1 短期改善策（1-2週間）

1. **2着予測の強化**
   - 決まり手別の2着パターンを統計化
   - 「逃げの場合の2着は2-3コースが多い」などのルール追加

2. **条件付き確率の導入**
   - P(2着=B | 1着=A) を計算
   - 1着予測が決まった後、2着・3着を条件付きで予測

### 5.2 中期改善策（1-2ヶ月）

1. **階層的予測モデルの強化**
   - `hierarchical_predictor.py` の活用度を上げる
   - Stage1: 1着予測、Stage2: 2着予測（1着条件付き）、Stage3: 3着予測

2. **決まり手予測の精度向上**
   - 決まり手を予測し、それに基づいて着順パターンを決定

### 5.3 長期改善策（3ヶ月以上）

1. **機械学習モデルの導入**
   - 現在のルールベースをベースラインに
   - XGBoost / LightGBM での予測モデル構築

2. **アンサンブル予測**
   - ルールベース + 統計ベース + MLベースの統合

## 6. 結論

### 6.1 現状評価
- **1着予測は比較的良好**（信頼度A: 81.8%, B: 71.1%）
- **2着・3着予測が弱点**（20-28%程度で信頼度による差が小さい）
- **3連単的中率は改善の余地大**（最大9.09%）

### 6.2 優先度の高い改善項目
1. 2着予測の条件付き確率モデル導入
2. 決まり手別の着順パターン統計の活用
3. 階層的予測モデルの強化

### 6.3 期待効果
- 2着的中率: +5-10pt 改善
- 3連単的中率: +2-3pt 改善
- 収益性: ROI +10-20%pt 改善の可能性
