## 1. 重要な発見

### オッズフィルターの有無で結果が大きく異なる

| 検証方法 | 説明 | 問題点 |
|:---------|:-----|:-------|
| 6年間データ（オッズなし） | 全レースの1着予測的中時の払戻を集計 | **実際の購入判定と異なる** |
| 2025年バックテスト（オッズあり） | BetTargetEvaluatorでオッズ判定後に集計 | **これが正しい検証** |

**結論**: 6年間データでは全条件が高ROI（1500-2000%）だったが、オッズフィルター適用後は一部条件が**逆効果**になることが判明。

## 4. 教訓

### 4.1 検証方法の重要性

```
× 6年間データ分析: 「1着予測が1着になった」を的中と定義 → ROI 2692%
○ バックテスト: 「買い目(1-2-3)が的中した」を的中と定義 → ROI 196.6%
```

**原因**: 6年間データでは「1着予測が1着になったレース」を的中としてカウントしていた（的中率82%）。しかし実際の3連単は「1-2-3着全て的中」が必要（的中率10%）。

| 計算方法 | 件数 | 的中 | 的中率 | ROI |
|:---------|:---:|:---:|:------:|:---:|
| 6年間データ（1着のみ） | 148 | 122 | 82% | 2692% |
| バックテスト（3連単） | 80 | 8 | 10% | 196.6% |

### 4.2 サンプル数の重要性

| 件数 | 信頼性 | 対応 |
|:----:|:------:|:-----|
| 100件以上 | 高 | 本番採用可 |
| 50-100件 | 中 | 要継続監視 |
| 50件未満 | 低 | 保留 |

D条件のモーター追加は32件しかなく、統計的に信頼できない。

### 4.3 「良い条件」を重ねても逆効果になることがある

```
A × A2（良い） × モーター40%+（良い） = ROI 70.3%（悪い）
```

**仮説**: A2級選手はモーター性能への依存度が高く、モーター40%+をフィルターにすると人気が集中し、オッズが下がる可能性。
