【7】改善提案: 新しい信頼度の枠組み
================================================================================

■ 現状の問題点
--------------------------------------------------------------------------------
1. 信頼度Aの的中率が69.7%と高いが、サンプル数が少ない（56,443件）
2. 信頼度B-Eの的中率の差が小さい（23.6% - 44.6%）
3. 信頼度が同じでも、会場・級別・コースによって精度にバラツキがある
4. オッズと信頼度が必ずしも連動していない

■ 新しい信頼度の設計方針
--------------------------------------------------------------------------------
【方針1】信頼度を5段階から7段階に拡張
  - S（スペシャル）: 的中率70%以上（現A+の一部）
  - A+（最高）: 的中率60-70%（現Aの一部）
  - A（高）: 的中率50-60%（現Bの上位）
  - B（中）: 的中率40-50%（現Cの上位）
  - C（やや低）: 的中率30-40%（現Dの上位）
  - D（低）: 的中率20-30%（現Eの上位）
  - E（最低）: 的中率20%未満

【方針2】信頼度を決める主要因子の見直し
  現在の因子:
    - 選手の級別（A1/A2/B1/B2）
    - 予測コース（1号艇が有利）
    - 会場特性（戸田など）
    - 勝率・2連率

  追加すべき因子:
    - オッズ情報（低オッズほど高信頼）
    - ST平均値とバラツキ
    - モーター性能（2連率）
    - 展示タイム
    - 決まり手傾向
    - 進入隊形（枠番とのズレ）

【方針3】会場別・級別の補正係数を導入
  - 会場別の基準精度を設定
  - 級別による信頼度の調整
  - コース別の信頼度の調整

【方針4】信頼度の動的調整
  - レース直前のオッズ変動を反映
  - 天候・波高などのリアルタイム情報を反映
  - 前日の展示タイムを反映

【8】具体的な実装案
================================================================================

■ ステップ1: 基礎的な信頼度スコアの算出
--------------------------------------------------------------------------------
信頼度スコア = 基本スコア + 補正スコア

基本スコア:
  - 級別: A1=40点, A2=30点, B1=20点, B2=10点
  - コース: 1号艇=30点, 2号艇=20点, 3号艇=15点, 4-6号艇=10点
  - 勝率: (勝率 × 2)点
  - 2連率: (2連率 × 1)点

補正スコア:
  - 会場別: 戸田=+10点, 江戸川=-5点, 平和島=-5点
  - オッズ: 10倍未満=+15点, 10-20倍=+10点, 20-30倍=+5点
  - モーター2連率: 40%以上=+5点, 30-40%=+3点
  - ST平均: 0.15以下=+5点, 0.15-0.17=+3点

■ ステップ2: スコアから信頼度への変換
--------------------------------------------------------------------------------
  - 120点以上: S（スペシャル）
  - 100-119点: A+（最高）
  - 80-99点: A（高）
  - 60-79点: B（中）
  - 40-59点: C（やや低）
  - 20-39点: D（低）
  - 20点未満: E（最低）

■ ステップ3: 検証と調整
--------------------------------------------------------------------------------
  1. 過去データで新信頼度を計算
  2. 各信頼度の的中率を検証
  3. スコア基準を調整
  4. 本番運用に適用

【結論】
================================================================================

現在の信頼度A/B/C/D/Eは以下の問題を抱えている:
  1. 信頼度Aのサンプル数が少なく、実用性が限定的
  2. 信頼度B-Eの精度差が小さく、区別が曖昧
  3. 会場・級別・コースの影響が十分に反映されていない
  4. オッズなどのリアルタイム情報が活用されていない

改善策:
  ✅ 信頼度を7段階（S/A+/A/B/C/D/E）に拡張
  ✅ スコアリング方式で信頼度を算出
  ✅ 会場・級別・コースの補正係数を導入
  ✅ オッズ・ST・モーター性能を考慮
  ✅ データ補完後に詳細検証
