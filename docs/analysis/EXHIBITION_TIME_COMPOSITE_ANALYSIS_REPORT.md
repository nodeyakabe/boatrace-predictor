## エグゼクティブサマリー

### 主要発見事項

1. **展示タイムは「単独」では効果が限定的だが、「複合」で真価を発揮**
   - 展示タイム順位単独: +3.42%/順位（ST順位の+6.25%に対して約半分）
   - ST1位 & 展示1位の複合: **+193%の1着率向上**（ベースライン16.91% → 48.96%）

2. **会場補正が極めて重要**
   - 展示タイムの平均値は会場によって6.70秒〜6.98秒まで大きく異なる
   - 「速い」「遅い」の基準は会場ごとに設定すべき

3. **相対差（独走パターン）が高い予測力を持つ**
   - 展示1位が2位より0.2秒以上速い場合: 1着率+27.75%向上

4. **会場別の展示タイム重要度に明確な差**
   - 高重要度: 徳山（相関0.279）、蒲郡（0.271）、丸亀（0.257）
   - 低重要度: 江戸川（0.150）、平和島（0.167）

```python
def calculate_exhibition_zscore(exhibition_time: float, venue_code: str) -> float:
    """
    会場補正済みのZ-scoreを計算

    Args:
        exhibition_time: 展示タイム（秒）
        venue_code: 会場コード

    Returns:
        Z-score（負=速い、正=遅い）
    """
    baseline = VENUE_EXHIBITION_BASELINES.get(venue_code, {'mean': 6.80, 'std': 0.10})
    return (exhibition_time - baseline['mean']) / baseline['std']


def calculate_exhibition_diff(race_exhibition_times: dict) -> dict:
    """
    レース内の展示タイム差を計算

    Args:
        race_exhibition_times: {pit_number: exhibition_time} の辞書

    Returns:
        {'diff_1st_2nd': 差, 'diff_1st_3rd': 差, ...}
    """
    sorted_times = sorted(race_exhibition_times.values())
    if len(sorted_times) < 3:
        return {}

    return {
        'diff_1st_2nd': sorted_times[1] - sorted_times[0],
        'diff_1st_3rd': sorted_times[2] - sorted_times[0],
    }


def get_venue_exhibition_weight(venue_code: str) -> float:
    """
    会場別の展示タイム重み係数を取得

    Args:
        venue_code: 会場コード

    Returns:
        重み係数（1.0 = 標準）
    """
    baseline = VENUE_EXHIBITION_BASELINES.get(venue_code, {'weight': 1.0})
    return baseline.get('weight', 1.0)
```

## まとめ

### 展示タイムの真の価値

1. **単独では効果が限定的**（ST順位の約半分）
2. **会場補正が必須**（0.28秒の会場差）
3. **相対差評価が有効**（独走パターンで+27.75%）
4. **STとの複合で真価を発揮**（ST1位 & 展示1位で+193%）
5. **会場による重要度の差が大きい**（徳山 vs 江戸川で相関差0.13）

### 実装優先度

1. **高**: ST × 展示の複合パターン（既存パターンの拡張）
2. **中**: 会場別展示タイム重み係数
3. **中**: 絶対値評価（Z-score）パターン
4. **低**: 相対差評価パターン（サンプル数が少ない）
