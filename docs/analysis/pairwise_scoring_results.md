# ペアワイズ相対スコアリング（アプローチ3）検証結果

## 概要

艇間の直接対決確率をモデル化し、相対的な強さから順位を予測するアプローチ。

### 理論的根拠

- 現在のモデルは各艇の**絶対スコア**を計算するが、実際のレースは**相対的な強さ**で決まる
- 艇1が艇2に勝つ確率 `P(1 > 2)` を直接モデル化
- 全ペアの勝率から最終順位を復元することで、より精度の高い予測が可能

### ペアワイズ特徴量

各艇ペア(i, j)に対して以下の相対特徴量を計算：

| 特徴量 | 説明 |
|--------|------|
| `score_diff` | 総合スコア差（i - j） |
| `win_rate_diff` | 勝率差 |
| `second_rate_diff` | 2連対率差 |
| `class_diff` | 級別差（A1=4, A2=3, B1=2, B2=1） |
| `avg_st_diff` | 平均ST差 |
| `exhibition_diff` | 展示タイム差 |
| `motor_2rate_diff` | モーター2連対率差 |
| `boat_2rate_diff` | ボート2連対率差 |
| `course_diff` | コース差 |
| `course_advantage` | コース有利度差 |
| `is_inner` | 内側フラグ |
| `i_score`, `j_score` | 各艇の絶対スコア |
| `i_course`, `j_course` | 各艇のコース |
| `i_class`, `j_class` | 各艇の級別 |
| `recent_form_diff` | 直近成績差 |
| `current_term_diff` | 当節成績差 |

### 順位復元アルゴリズム

全ペアの勝率 `P(i > j)` から最終順位を決定：

```python
# 方法A: 期待勝数カウント（採用）
for boat_i in boats:
    win_count[i] = sum(P(i > j) for j in boats if j != i)
# win_countの降順でソート
```

## 推奨設定

### 最適パラメータ

| パラメータ | 推奨値 | 説明 |
|------------|--------|------|
| gamma | 0.5 | 絶対スコアとペアワイズスコアの統合重み |
| method | 'win_count' | 順位復元方法（期待勝数カウント） |

### 統合方法

```python
# 統合スコア計算
integrated_score = gamma * absolute_score + (1 - gamma) * pairwise_score

# gamma=0.5の場合
# 絶対スコア 50% + ペアワイズスコア 50%
```
