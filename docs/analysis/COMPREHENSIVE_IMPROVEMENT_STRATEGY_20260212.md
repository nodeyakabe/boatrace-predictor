- 信頼度が同じでも、会場・級別・コースによって精度にバラツキがある

**新しい信頼度の枠組み**:

| 信頼度 | 目標的中率 | 現状 |
|-------|----------|------|
| **S（スペシャル）** | 70%以上 | 新設 |
| **A+（最高）** | 60-70% | 現A+の一部 |
| **A（高）** | 50-60% | 現Bの上位 |
| **B（中）** | 40-50% | 現Cの上位 |
| **C（やや低）** | 30-40% | 現Dの上位 |
| **D（低）** | 20-30% | 現Eの上位 |
| **E（最低）** | 20%未満 | - |

**スコアリング方式**:
```
信頼度スコア = 基本スコア + 補正スコア

基本スコア:
  - 級別: A1=40点, A2=30点, B1=20点, B2=10点
  - コース: 1号艇=30点, 2号艇=20点, 3号艇=15点, 4-6号艇=10点
  - 勝率: (勝率 × 2)点
  - 2連率: (2連率 × 1)点

補正スコア:
  - 会場別: 戸田=+10点, 江戸川=-5点, 平和島=-5点
  - オッズ: 10倍未満=+15点, 10-20倍=+10点, 20-30倍=+5点
  - モーター2連率: 40%以上=+5点, 30-40%=+3点
  - ST平均: 0.15以下=+5点, 0.15-0.17=+3点

スコアから信頼度への変換:
  - 120点以上: S（スペシャル）
  - 100-119点: A+（最高）
  - 80-99点: A（高）
  - 60-79点: B（中）
  - 40-59点: C（やや低）
  - 20-39点: D（低）
  - 20点未満: E（最低）
```
