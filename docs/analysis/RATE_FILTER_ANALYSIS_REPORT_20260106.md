## 7. 最終推奨

### 実装すべき条件: **なし**

すべての候補条件は以下の理由により**実装を見送る**ことを推奨:

| 条件 | 判定 | 主な理由 |
|:-----|:----:|:---------|
| A x A1 x 14-16 + 3連率 >= 35%除外 | **見送り** | サンプルサイズ不足（年3-5件）、2023/2025年で0%ROI |
| A x A1 x 14-16 + 2連率 >= 25%除外 | **見送り** | サンプルサイズ不足、2023年で0%ROI |
| A x A1 x 10-12 + 2連率 < 55%除外 | **見送り** | 2021/2022年でROI悪化、年度安定性不足 |
| C x 20-30 x B1 + 2連率 >= 25%除外 | **継続監視** | 有望だが2021/2025年で悪化、除外率80% |
| D x 35-60 + 2連率 >= 25%除外 | **継続監視** | 有望だが2022/2024年で赤字 |

### p値の解釈について

前回の分析で見つかったp値（p=0.0305, p=0.0097, p=0.0995）は、以下の理由で**見かけ上の統計的有意性**である可能性が高い:

1. **多重比較問題**: 複数の閾値・条件を探索しており、偶然に有意な組み合わせが見つかりやすい
2. **サンプルサイズの小ささ**: 特にA x A1 x 14-16条件は年間3-5件と極めて少ない
3. **年度間安定性の欠如**: クロスバリデーションで一貫した改善が見られない年度がある
4. **高い除外率**: 80%以上のデータを除外しており、残りデータが偏っている可能性

### 継続監視の推奨

以下の条件は、データ蓄積後に再評価することを推奨:

1. **C x 20-30 x B1 + 2着予測2連率 >= 25%除外**
   - 現状: 616件（年間約100件）
   - 目標: 各年150件以上で再検証
   - 監視指標: 年度別ROI、黒字年度数

2. **D x 35-60 + 2着予測2連率 >= 25%除外**
   - 現状: 528件（年間約90件）
   - 目標: 各年150件以上で再検証
   - 監視指標: 2022年、2024年の改善傾向

## 9. 結論

**元の分析で見つかった有意なp値は、サンプルサイズの小ささと多重比較により生じた偶然の結果である可能性が高い。**

連対率フィルターによる除外条件は**現時点では実装しない**ことを強く推奨する。

ただし、C x 20-30 x B1とD x 35-60条件については有望な傾向が見られるため、データ蓄積を続け、各年度150件以上のサンプルが確保できた段階で再評価することを推奨する。
