# P-6-2 決まり手別分岐ロジック強化（まくり系対策）

## 分析レポート

### 背景

P-5の分析で判明した決まり手別予測精度の弱点:
- 決まり手「逃げ」: 81.6%精度（強い）
- 決まり手「まくり」: 21.5%精度（弱い）
- 決まり手「差し」: 16.9%精度（弱い）
- 決まり手「まくり差し」: 13.5%精度（最弱）

### 分析結果

#### 1. 決まり手の全体分布

| 決まり手 | 件数 | 割合 |
|---------|------|------|
| 逃げ | 72,869 | 54.5% |
| まくり | 18,018 | 13.5% |
| 差し | 16,500 | 12.3% |
| まくり差し | 14,460 | 10.8% |
| 抜き | 9,376 | 7.0% |

#### 2. コース別まくり系発生傾向

| コース | 主な決まり手 | 件数 |
|--------|-------------|------|
| 2コース | 差し | 8,584 |
| 2コース | まくり | 2,900 |
| 3コース | まくり | 4,231 |
| 3コース | まくり差し | 4,131 |
| 4コース | まくり | 4,547 |
| 4コース | まくり差し | 2,613 |
| 5コース | まくり差し | 3,281 |

**知見**:
- 3-4コースはまくりの主力コース
- 5-6コースはまくり差し主体

#### 3. 1コース級別別 敗北率

| 級別 | 総レース | 敗北率 |
|------|---------|--------|
| B2 | 2,349 | **65.1%** |
| B1 | 33,971 | **54.1%** |
| A2 | 31,582 | 36.6% |
| A1 | 32,013 | 28.1% |

**知見**:
- 1コースB1/B2は敗北率が高い（まくられリスク高）
- A1は約72%の勝率を維持

#### 4. 1コースSTとまくられ率の関係

| 1コースST帯 | 総レース | まくられ率 |
|------------|---------|----------|
| 0.00-0.09秒 | 18,686 | 13.5% |
| 0.10-0.14秒 | 26,455 | 18.4% |
| 0.15-0.19秒 | 26,714 | 25.5% |
| 0.20-0.24秒 | 13,801 | **34.9%** |
| 0.25秒以上 | 9,236 | **51.6%** |

**知見**:
- 1コースのSTが0.20秒以上だとまくられ率が急上昇
- 0.25秒以上では半数以上がまくられる

#### 5. スタートタイミング差の影響

| ST比較 | 件数 | 勝者平均ST | 1C平均ST |
|--------|------|-----------|---------|
| 勝者がスタート早い | 15,835 | 0.126秒 | 0.206秒 |
| 1Cがスタート早い | 4,946 | 0.259秒 | 0.145秒 |

**知見**:
- まくり成功の約72%は勝者のSTが早いケース
- 1コースのST遅れがまくり成功の主要因

#### 6. 会場別まくり発生率

| 会場 | まくり発生率 |
|------|------------|
| 戸田(02) | **36.1%** |
| 平和島(04) | 29.6% |

| ... | ... |

**知見**:
- 会場により13%以上の差がある
- 戸田は全国で最もまくりが多い

#### 7. まくり成功者の平均ST（コース別）

| コース | 決まり手 | 平均ST |
|--------|---------|--------|
| 2コース | まくり | 0.160秒 |

**知見**:
- 4コース・6コースのまくり成功者はSTが特に早い

## 実装内容

### 1. MakuriRiskEvaluator クラス

**ファイル**: `src/prediction/makuri_risk_evaluator.py`

まくりリスクを総合評価するエンジン:

```python
class MakuriRiskEvaluator:
    """まくり系決まり手のリスク評価エンジン"""

    def evaluate_makuri_risk(self, race_context, entries, course1_st=None):
        """
        まくりリスクを総合評価

        評価要因:
        1. 1コース級別リスク（B1/B2は高リスク）
        2. 1コースSTリスク（0.20秒以上は高リスク）
        3. 会場リスク（戸田等は高リスク）

        Returns:
            MakuriRiskAssessment
        """
```

### 2. 評価結果の構造

```python
@dataclass
class MakuriRiskAssessment:
    course1_risk_level: str  # "high", "medium", "low"
    course1_makuri_prob: float  # 1コースがまくられる確率
    makuri_candidates: List[Tuple[int, float, str]]  # まくり候補
    confidence: float  # 評価の信頼度
    factors: Dict[str, any]  # 評価要因の詳細
```

### 3. kimarite_flow_predictor.py への統合

- `predict_kimarite_probabilities()`: まくり系の確率を動的に補正
- `predict_full_ranking()`: スコア調整とまくりリスク情報の付加

### 4. feature_flags での制御

```python
'makuri_risk_adjustment': True,  # P-6-2タスク
```

フラグOFFで従来動作に戻せる。

## 改善効果（期待）

1. **まくり展開の予測精度向上**: +2-4pt
   - 1コースB1/B2の場合に外コースのまくり候補を適切に評価
   - ST差が大きい場合にまくりシナリオの確率を上げる

2. **2着・3着精度向上**:
   - まくり展開時の2着（差されコース）を適切に予測
   - まくり差し展開での3着候補を改善

3. **会場別対応**:
   - 戸田等のまくり多発会場で適切なリスク評価
