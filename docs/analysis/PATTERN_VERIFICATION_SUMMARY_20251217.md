## 🎯 ベースライン差-1.31ptの分解

### 既知の要因

| 要因 | 影響 | 備考 |
|------|------|------|
| BEFORE_PATTERNS_1ST | ±0.00pt | ポジティブとネガティブが相殺 |
| BEFORE_PATTERNS_TOP3 | -0.77pt | わずかに悪化 |
| **不明な要因** | **-0.54pt** | 残り |

### 未検証の要因候補

1. **BEFORE_PATTERNS_2ND**（2着用パターン）
   - PRE2-3位に適用されるパターン
   - PRE1位のスコアには影響しないはずだが、再ソート後の順位に影響する可能性

2. **BEFORE_PATTERNS_3RD**（3着用パターン）
   - PRE3-4位に適用されるパターン
   - 同様に、間接的に順位に影響する可能性

3. **パターン適用順序の問題**
   - 複数パターンが重複適用される際の倍率計算
   - 積算方式が適切かどうか

4. **比較対象のベースライン定義**
   - 前回の検証（51.30% vs 52.61% = -1.31pt）
   - 今回の検証（52.03%がベースライン）
   - 定義が異なる可能性
