**作成日**: 2025-12-17

**検証期間**: 2024年データ（5,195レース）

---

## エグゼクティブサマリー

直前情報（展示タイム、STタイム）の活用を最適化し、**統計的に有意な的中率改善（+1.92pt）** を達成しました。

### 主要成果

| 指標 | 最適化前 | 最適化後 | 改善幅 |
|-----|---------|---------|-------|
| **1着的中率** | 49.37% | **51.30%** | **+1.92pt** ✅ |
| 3着以内的中率 | 79.02% | 80.33% | +1.31pt |
| **統計的有意性** | p=0.0039（悪化） | **p=0.0497（改善）** | ✅ |

**ROI影響**: 的中率+1.92ptは、年間収支で約+5%〜10%の改善に相当すると推定

## リスクと制約事項

### 1. ベースラインとの差分（-1.31pt）

**現状**: 最適化後の的中率51.30%は、ベースライン52.61%より**-1.31pt低い**

**原因仮説**:
1. TOP3パターンを1着的中率で評価している可能性
2. ベースラインが異なる手法を使用している可能性
3. 会場別・信頼度別の最適化が不十分

**対応策**:
- TOP3パターンは3着以内的中率で再評価
- ベースラインとの詳細比較分析
- 会場別・信頼度別の個別最適化

### 2. サンプル数の不均衡

| パターン | サンプル数 | 信頼性 |
|---------|-----------|-------|
| pre1_st1_ex1 | 131 | ⚠️ やや少ない |
| pre1_st6 | 125 | ⚠️ やや少ない |
| pre1_3_st1 | 34,985 | ✅ 十分 |

**対応**: 2025年データで再検証し、サンプル数増加後に倍率を再調整

### 3. 過学習リスク

**懸念**: 2024年データでの最適化が2025年以降でも有効か不明

**対応策**:
- 2020-2023年データでの交差検証
- 2025年データでの前向き検証
- 定期的な倍率の見直し

## 付録

### A. 技術的詳細

#### パターンマッチング処理フロー

```python
def apply_pattern_bonus(predictions, race_id):
    # 1. BEFORE情報取得
    before_data = get_before_data(race_id)

    # 2. 順位マップ作成
    exhibition_rank_map = build_exhibition_rank_map(before_data)
    st_rank_map = build_st_rank_map(before_data)
    pre_rank_map = build_pre_rank_map(predictions)

    # 3. 各艇にパターンチェック
    for pred in predictions:
        matched_patterns = check_patterns(
            pre_rank_map[pit_number],
            exhibition_rank_map[pit_number],
            st_rank_map[pit_number]
        )

        # 4. 最高倍率適用
        final_multiplier = max(p['multiplier'] for p in matched_patterns)
        pred['total_score'] *= final_multiplier

    # 5. 再ソート
    predictions.sort(key=lambda x: x['total_score'], reverse=True)

    return predictions
```

#### 統計的検定手法

**使用検定**: 両側比率検定（Two-proportion Z-test）

**帰無仮説**: 最適化前後で的中率に差がない（p1 = p2）

**対立仮説**: 最適化後の的中率が高い（p1 < p2）

**検定統計量**:
```
Z = (p2 - p1) / sqrt(p_pooled * (1 - p_pooled) * (1/n1 + 1/n2))
```

**有意水準**: α = 0.05

**効果量（Cohen's h）**:
```
h = 2 * (arcsin(sqrt(p2)) - arcsin(sqrt(p1)))
```
