# before予測 不的中パターン分析レポート

**作成日**: 2025-12-24
**分析対象**: 2020-2025年before予測データ

---

## エグゼクティブサマリー

### 主要発見

1. **3点買いは的中率を上げるが、ROIを下げる傾向がある**
   - 例: 条件1で的中率+7.1pt、ROI-11.6pt
   - 例外: 条件3（A x 20-30）は3点買いでROI+16.3pt改善

2. **会場・月・レース番号フィルターで大幅改善が可能**
   - 条件1: ROI 102.7% → 141.6%（+38.9pt）
   - 条件3: ROI 62.5% → 154.2%（+91.7pt）
   - 条件5: ROI 115.1% → 211.3%（+96.2pt）

3. **不的中の主要パターン**
   - 1着は当たるが2着で外す: 全条件で最大の損失要因
   - 1-2着は当たるが3着で外す: 3点買いで70-80%回収可能

## 2. 3点買いでの改善可能性

### 2.1 買い方の定義

| 買い目 | 配分 |
|--------|------|
| 1-2-3（本線） | 200円 |
| 1-2-4 | 100円 |
| 1-2-5 | 100円 |
| **合計** | **400円/R** |

### 2.2 各条件での効果

| 条件 | 現行ROI | 3点ROI | 変化 | 的中率変化 | 判定 |
|------|---------|--------|------|------------|------|
| C x 20-30 x B1 | 102.7% | 91.1% | **-11.6pt** | +7.1pt | NG |
| B x 50-100 x B1 | 218.1% | 156.2% | **-61.8pt** | +3.4pt | NG |
| A x 20-30 | 62.5% | 78.8% | **+16.3pt** | +9.6pt | **OK** |
| C x 30-50 x A2 | 80.7% | 72.3% | **-8.4pt** | +5.8pt | NG |
| D x 40-50 x B1 | 115.1% | 97.1% | **-18.0pt** | +4.0pt | NG |

### 2.3 結論

**3点買いは条件3（A x 20-30）のみ有効**

理由:
- 条件3は元々ROIが低い（62.5%）ため、的中率向上の恩恵が大きい
- 高ROI条件では、3点目の低オッズ的中が全体ROIを希釈してしまう

## 3. フィルターによる改善提案

### 3.1 条件1: C x 20-30 x B1

#### 推奨フィルター

**会場除外**（ROI<70%）:
- 尼崎(03), 蒲郡(07), 三国(10), 鳴門(14), 児島(16), 下関(19), 芦屋(21)

**月除外**:
- 5月, 9月

#### 効果

| 設定 | 件数 | 的中 | ROI |
|------|------|------|-----|

| 会場フィルター | 2,122 | 114 | **128.7%** |

## 4. 最終提案

### 4.1 即時採用可能

| 条件 | フィルター | 元ROI | 改善後ROI | 件数減 |
|------|------------|-------|-----------|--------|
| C x 20-30 x B1 | 会場+月除外 | 102.7% | **141.6%** | -42% |
| A x 20-30 | 会場+R#限定 | 62.5% | **154.2%** | -85% |

### 4.2 経過観察・追加検証

| 条件 | フィルター | 元ROI | 改善後ROI | 課題 |
|------|------------|-------|-----------|------|
| C x 30-50 x A2 | 会場限定 | 80.7% | 167.4% | 2020-21年が弱い |
| D x 40-50 x B1 | 月限定 | 115.1% | 211.3% | 2021-22年が弱い |
| B x 50-100 x B1 | - | 218.1% | - | サンプル不足 |

### 4.3 3点買いの適用

| 条件 | 3点買い推奨 | 理由 |
|------|-------------|------|
| A x 20-30 | **適用推奨** | ROI+16.3pt改善 |
| 他の条件 | 適用非推奨 | ROI低下 |
