## 1. 3層アーキテクチャの現状

### 1.1 構成図

```
┌─────────────────────────────────────────────────┐
│                レースデータ入力                   │
└─────────────────────────────────────────────────┘
                      ↓
┌─────────────────────────────────────────────────┐
│  【戦略B】順位予測（ExtendedScorer）              │
│  ─────────────────────────────────────────────  │
│  • 級別スコア、モータースコア、STスコア等を総合   │
│  • 信頼度A/B/C/D/E判定（hierarchical_predictor）  │
│  • 出力: 予測順位[1,2,3,4,5,6] + 信頼度           │
└─────────────────────────────────────────────────┘
                      ↓
┌─────────────────────────────────────────────────┐
│  【フィルターC】購入判定（BetTargetEvaluator）    │
│  ─────────────────────────────────────────────  │
│  • オッズ範囲チェック（30-60倍、60-100倍等）     │
│  • 1コース級別チェック（A1級、A2級等）           │
│  • ネガティブパターン除外（P-2タスク追加）        │
│  • 穴狙いパターン復活（upset_pattern_filter）    │
│  • 出力: 購入対象/対象外                         │
└─────────────────────────────────────────────────┘
                      ↓
┌─────────────────────────────────────────────────┐
│  【パターンH】買い目生成（MultiBetGenerator）     │

│  • 1-2軸固定、3着を3〜5位に分散                  │
│  • 傾斜配分: 1-2-3:200円, 1-2-4:100円, 1-2-5:100円│
│  • 合計: 400円/レース                            │
└─────────────────────────────────────────────────┘
```

## 2. 予測データの現状

### 2.1 年度別advance予測状況

| 年度 | 総レース数 | 生成済み | 生成率 | 信頼度A | 信頼度B | 信頼度C | 信頼度D | 信頼度E |
|------|-----------|----------|--------|---------|---------|---------|---------|---------|
| 2022 | 35,883 | 1,628 | **4.5%** | 0 | 0 | 0 | 4,301 | 5,467 |
| 2023 | 9,084 | 1,618 | **17.8%** | 0 | 0 | 0 | 3,033 | 6,675 |
| 2024 | 14,014 | 1,180 | **8.4%** | 0 | 0 | 0 | 2,737 | 4,343 |
| 2025 | 18,980 | 17,724 | **93.4%** | 964 | 7,049 | 20,043 | 38,393 | 39,887 |

### 2.2 問題点

**2022-2024年のデータ問題**:
- `generate_advance_ultrafast.py`で生成された
- `hierarchical_predictor=False`のため信頼度D/Eのみ
- 信頼度A/B/Cが存在しないため、本来の購入条件でテスト不可

**再生成の目的**:
- 完全なアルゴリズム（hierarchical_predictor=True）で再生成
- 信頼度A-E全てを持つデータで公平な4年間比較を可能に

### 2.3 再生成進捗

バックグラウンドで`generate_advance_fast.py`を使用して再生成中。
推定完了時間: 4-6時間（残り約95%）

## 4. 今回のセッションでの作業

### 4.1 実施した作業

1. **4年間パターン分析（Opus分析）**
   - `docs/TRIFECTA_PATTERN_ANALYSIS_4YEARS.md` を作成

   - `src/betting/filter_engine.py` に追加

   - オッズ100倍以上×予測1着6コース → 的中率0%パターン除外
   - 荒れ会場×予測1着1コース → 的中率1.5-2%パターン除外

3. **穴狙いパターンフィルタ実装**
   - オッズ30-100倍×予測1着5コース → 安定ROI+10%以上で復活

4. **2022-2024年advance予測再生成開始**
   - 完全アルゴリズムで再生成中（バックグラウンド）

## 7. 再生成の意義

### 7.1 再生成が必要だった理由

| 項目 | 旧データ | 新データ |
|------|----------|----------|
| 生成スクリプト | ultrafast版 | fast版 |
| hierarchical_predictor | 無効（False） | 有効（True） |
| 信頼度分布 | D/Eのみ | A-E全て |
| 信頼度C/D条件テスト | 不可能 | 可能 |
| 4年間比較 | 不公平 | 公平 |

### 7.2 再生成の価値

1. **公平な比較基盤**: 2022-2025年を同一アルゴリズムで比較可能
2. **正確な条件検証**: 信頼度A/B/C全てでROI検証可能
3. **過学習チェック**: 2022-2023年で発見→2024-2025年で検証
4. **年度間安定パターン**: 複数年で安定した条件を発見可能

### 7.3 再生成しても変わらない現実

- 基本戦略のROIがマイナスという事実
- 3連単的中率1.5%程度という限界
- 信頼度C条件の非効率性

## 8. 結論

### 8.1 現状認識

**「プラス収支」は幻想だった**

- 従来報告されていた好成績は計算ロジックの欠陥による
- 正確なバックテストでは年間-5万円程度のマイナス
- 一部条件（信頼度D）のみ微プラス（ROI 102-104%）

### 8.2 今後の方針

1. **信頼度C条件を除外**: 確実なマイナス要因を排除
2. **信頼度D条件に集中**: 微プラスが確認された条件のみ運用
3. **ネガティブパターン除外**: P-2タスクで実装済み
4. **再生成完了後に全面検証**: 4年間の安定パターンを探索
5. **2連単への移行検討**: 的中率向上のため

### 8.3 再生成完了後のアクション

1. 信頼度分布の確認（A-E全てあることを確認）
2. 4年間のROI分析（年度別・条件別）
3. 年度間で安定したプラス条件の探索
4. 過学習チェック（2022-2023で発見→2024-2025で検証）
5. 新たな購入条件の策定
