作成日: 2025-12-17

## 1. 現状の直前情報使用状況

### 1.1 直前情報の流れ

```
[race_details テーブル]
    ↓
[BeforeInfoScorer] - 115点満点でスコアリング
    ↓
[_apply_beforeinfo_integration] - PRE_SCOREと統合
    ↓
[_apply_pattern_bonus] - パターンボーナス適用（現在有効）
    ↓
[最終予測結果]
```

## 4. 最適化の余地

### 4.1 発見された問題点

1. **信頼度B/Cで直前情報が逆効果**
   - advance: 71.49% / 55.77%
   - before: 71.20% / 55.24%
   - 原因: PRE_SCOREが高い場合、直前情報による順位変動が悪影響

2. **予測順位変動時の精度低下**
   - advance1位→before順位低下: 勝率25.59%（大幅低下）
   - advance1位→before順位維持: 勝率52.90%

3. **未使用特徴量の存在**
   - isshu_time（一周タイム）: 強い勝率相関あり
   - mawariashi_time（回り足タイム）: 中程度の相関

4. **2025年STデータ欠損**
   - 42%のレースでST情報が欠損
   - パターンボーナス適用率の低下につながる

5. **チルト角度の活用不足**
   - 現在: コース依存の単純評価のみ
   - 実データ: 外コース（4-6）で+チルト時に勝率向上確認

### 4.2 使われていない直前情報

| 項目 | DBカラム | 欠損率(2025) | 活用可能性 |
|------|----------|--------------|------------|
| 一周タイム | isshu_time | 96.6% | **高い**（勝率相関強） |
| 回り足タイム | mawariashi_time | 96.4% | 中程度 |
| 周回タイム | chikusen_time | 96.7% | 低い |

### 4.3 統合比率の問題

現在のパターンボーナス方式では:
- PRE_SCORE × パターン倍率（1.0〜1.411）
- BEFORE_SCOREは直接統合されない

**代替案（アーカイブ済み）:**
- 0.6:0.4統合 → 悪化
- 動的統合 → 逆相関
- フラグ調整 → -3.65%悪化

## 5. 具体的な改善提案（優先度付き）

### 優先度A（高い効果が期待できる）

#### A1. 信頼度別パターン適用の最適化
**現状:** 信頼度A/Eではパターンスキップ、B/Cでは適用
**提案:** B/Cでもパターン適用を抑制または無効化

```python
# 現在のコード
if top_confidence in ['A', 'E']:
    # パターンスキップ

# 提案
if top_confidence in ['A', 'B', 'C']:  # B, Cを追加
    # パターンスキップ（または倍率を1.0-1.1に制限）
```

**期待効果:** 信頼度B/Cでの逆効果を防止（+0.3〜0.5pt改善見込み）

#### A2. 予測順位変動の保守的ハンドリング
**現状:** BEFORE情報でPRE_SCOREより順位が下がることを許容
**提案:** PRE_SCORE1位の艇の順位低下を制限

```python
# 提案ロジック
if advance_rank == 1 and before_rank > 1:
    # PRE1位の順位低下を防ぐために倍率を維持
    final_multiplier = max(final_multiplier, 1.0)
```

**期待効果:** 予測順位変動による精度低下を防止（+2〜3pt改善見込み）

#### A3. STデータ欠損時の展示タイム活用強化
**現状:** ST欠損時はパターンボーナス適用不可
**提案:** 展示タイム単独でもボーナス適用可能に

```python
# 新パターン追加案
{
    'name': 'pre1_ex1_no_st',
    'description': 'PRE1位 & 展示1位（ST欠損時）',
    'multiplier': 1.20,  # 控えめな倍率
    'condition': lambda pre_rank, ex_rank, st_rank: pre_rank == 1 and ex_rank == 1 and st_rank is None
}
```

**期待効果:** 2025年データでの適用率向上（特にSTデータ欠損42%への対応）

### 優先度B（中程度の効果が期待できる）

#### B1. isshu_time（一周タイム）の活用
**現状:** 未使用（データ充実度3.4%）
**提案:** データ収集率向上＋スコアリング追加

```python
# 新しいスコアリング項目
self.ISSHU_TIME_WEIGHT = 5.0  # 一周タイム（5点）

def _calc_isshu_time_score(self, pit_number, isshu_times):
    # 順位別スコア（勝率相関が強いため）
    rank_scores = {1: 5.0, 2: 3.5, 3: 2.0, 4: 1.0, 5: 0.5, 6: 0.0}
```

**期待効果:** 一周タイム1位の勝率38.66%を活用可能（データ収集率向上が前提）

#### B2. チルト×コース×風向の交互作用強化
**現状:** 基本的なチルト評価のみ
**提案:** 風向との組み合わせ評価を強化

```python
# 提案
if wind_direction in ['南', '南東', '南西'] and wind_speed >= 3:
    # 追い風時
    if course >= 4 and tilt >= 0.5:
        score += 4.0  # 現在3.0 → 4.0に増加
```

**期待効果:** 外コースでの+チルト効果を正しく評価

#### B3. 信頼度D/E専用パターンの追加
**現状:** 全信頼度で同じパターン適用
**提案:** D/E専用の強化パターン追加

**期待効果:** D/Eでの大幅改善効果（+6.46pt, +16.57pt）をさらに活用
