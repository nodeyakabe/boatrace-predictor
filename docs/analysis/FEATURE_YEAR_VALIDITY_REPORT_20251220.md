# フィーチャーフラグ年度間妥当性検証レポート

**分析日**: 2025-12-20
**分析者**: Claude Opus 4.5
**データ期間**: 2024年1月 - 2025年11月

---

## エグゼクティブサマリー

### 重大な発見

購入条件の年度間分析で判明した問題（2024年ROI 71.5% vs 2025年ROI 136.0%、差異64.5pt）を受けて、現在有効なフィーチャーフラグの年度間妥当性を検証しました。

**結論**: 現在有効な14個のフィーチャーのうち、**7個は2025年データのみで検証**されており、過剰適合のリスクがあります。

### 信頼性分類サマリー

| カテゴリ | 件数 | フィーチャー |
|---------|------|-------------|
| **信頼できる（維持推奨）** | 7 | 構造的機能 + 長期運用実績 |
| **要検証（2024年検証必要）** | 7 | 2025年のみで検証 |

## 2. 過剰適合リスク評価

### 2.1 リスク評価基準

- **低リスク**: 構造的機能、または両年度で検証済み
- **中リスク**: 2025年のみで検証、効果の年度変動可能性あり
- **高リスク**: 購入条件と密接に関連、年度間ギャップが大きい可能性

### 2.2 年度間モデルドリフトの実例

**rank23_odds_calibration の事例**（不採用になった施策）:

| 2024年 | +2.04pt | 有効 |
| 2025年 | ±0.00pt | 効果消失 |

この事例は、年度間でモデルの効果が大きく変動する可能性を示しています。

## 4. 推奨アクション

### 4.1 即時対応（優先度: 高）

#### 1. ab_rank_special_betting の年度間検証

**現状**:
- 2025年データで +17.2pt 効果確認
- 有効条件: Bランク × 50-100倍帯（ROI 512%）、A+Bランク × 1コースB1級（ROI 154%）

**リスク**:
- 購入条件分析で 2024年ROI 71.5%（赤字）が判明
- ab_rank_special_betting が有効化される条件と重複している可能性

**対応**:
```python
# 検証コマンド例
python scripts/backtest_ab_rank_2024.py --start-date 2024-01-01 --end-date 2024-12-31
```

#### 2. kimarite_flow_prediction / makuri_risk_adjustment の年度間検証

**現状**:
- 2025年12月に実装
- 5%調整で +4.1pt 効果

**リスク**:
- 決まり手パターン（逃げ、差し、まくり等）が年度で変化する可能性
- 2024年のデータでは異なる傾向を示す可能性

**対応**:
```python
# 検証コマンド例
python scripts/backtest_kimarite_2024.py --start-date 2024-01-01 --end-date 2024-12-31
```

### 4.2 中期対応（優先度: 中、1週間以内）

#### 3. pairwise_scoring の年度間検証

**現状**:
- 学習データ: 2024年1-10月（11,121レース）
- 検証データ: 2025年11月（482レース）
- 効果: 2着+7.3pt, 3着+3.9pt, ROI+1.7pt

**リスク**: 中程度
- 学習は2024年だが、検証は2025年のみ
- 2024年データでの効果未確認

**対応**:
- 2024年11-12月データでバックテスト実施
- 効果が維持されるか確認

#### 4. second_place_specialized の年度間検証

**現状**:

**リスク**: 中程度
- 2着パターンが年度で変化する可能性

**対応**:
- 2024年データでバックテスト実施

### 4.3 維持推奨（優先度: 低）

1. 2024年データで効果測定

## 7. 結論

### 主要な発見

1. **現在有効な14機能のうち7機能は2025年のみで検証**されており、過剰適合のリスクがある

2. **rank23_odds_calibrationの事例**が示すように、年度間でモデルの効果が大きく変動する可能性がある

3. **ab_rank_special_betting**は購入条件と密接に関連しており、最もリスクが高い

### 推奨される対応

| 優先度 | 対応内容 | 期限 |
|--------|---------|------|
| 高 | ab_rank_special_betting の2024年検証 | 即時 |
| 高 | kimarite_flow_prediction / makuri_risk_adjustment の2024年検証 | 3日以内 |
| 中 | pairwise_scoring / second_place_specialized の2024年検証 | 1週間以内 |
| 低 | confidence_based_switching / motor_capsizing_penalty の2024年検証 | 2週間以内 |

### 今後の方針

1. **新規施策は必ず両年度で検証**する
2. **年度間差が30pt以上の場合は採用保留**する
3. **月次で有効フィーチャーの効果を再測定**する
4. **モデルドリフトを早期検出**する仕組みを構築する

---

*本レポートは2024年1月-2025年11月のデータに基づいています。将来の市場環境変化により結果が異なる可能性があります。*
