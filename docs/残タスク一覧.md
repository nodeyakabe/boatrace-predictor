### P4完了後チェックリスト（2025年再生成完了後に実施）

#### 1. データ正常性確認（SQL）

```sql
-- exhibition_time 充足率（2025年、目標90%+）
SELECT COUNT(*) as total,
  COUNT(CASE WHEN exhibition_time IS NOT NULL AND exhibition_time > 0 THEN 1 END) as has_et,
  ROUND(COUNT(CASE WHEN exhibition_time IS NOT NULL AND exhibition_time > 0 THEN 1 END)*100.0/COUNT(*),1) as pct
FROM race_details rd JOIN races r ON rd.race_id = r.id WHERE r.race_date LIKE '2025%';

-- before予測 generated_at 確認（全年度が2026-03-09以降か）
SELECT strftime('%Y', r.race_date) as year, MAX(p.generated_at) as latest, MIN(p.generated_at) as oldest
FROM race_predictions p JOIN races r ON p.race_id = r.id
WHERE p.prediction_type = 'before' AND r.race_date >= '2020-01-01' AND r.race_date < '2026-01-01'
GROUP BY year ORDER BY year;

-- A率確認（全年度 2〜9%）
SELECT strftime('%Y', r.race_date) as year,
  ROUND(SUM(CASE WHEN p.confidence='A' THEN 1 ELSE 0 END)*100.0/COUNT(*),1) as a_rate
FROM race_predictions p JOIN races r ON p.race_id = r.id
WHERE p.prediction_type='before' AND r.race_date >= '2020-01-01' AND r.race_date < '2026-01-01'
GROUP BY year ORDER BY year;
```
