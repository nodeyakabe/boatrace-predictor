## 🎯 予測精度向上プロジェクト（2025-12-19策定）

### 概要：予測パイプライン5層構造

```
【第1層】基本スコア
    ↓ 選手の実力・モーター性能・コース有利を点数化
【第2層】拡張スコア
    ↓ 展示タイム・スタートタイミング・直近成績を加味
【第3層】環境補正
    ↓ 風向き・風速・潮の満ち引きで調整
【第4層】直前情報パターン
    ↓ 「このパターンなら勝つ」という法則を適用
【第5層】AI統合
    ↓ 機械学習モデルで最終調整
【出力】1着〜6着の順位予測 + 信頼度（A〜D）
```

### P-2. 選手間相性スコアの強化 🔴

**現状の課題**:
- 級別（A1/A2/B1/B2）のみで選手実力を評価
- 直近の調子が反映されていない
- 「級別では劣るが最近調子がいい選手」を見逃している

**改善案**:

| 項目 | 現状 | 改善案 |
|------|------|--------|
| 級別評価 | A1=10pt, A2=7pt, B1=4pt, B2=1pt | ✅ 維持 |
| 直近成績 | なし | ✅ **新規追加**: 直近10走の着順平均を加味 |
| 調子係数 | なし | ✅ **新規追加**: 直近5走が好調なら+係数 |

**計算式（案）**:
```
相性スコア = 級別スコア × 調子係数

調子係数 = 1.0 + (直近5走平均着順 - 3.5) × (-0.1)
  例: 直近5走平均 2.0着 → 1.0 + (2.0 - 3.5) × (-0.1) = 1.15
  例: 直近5走平均 4.5着 → 1.0 + (4.5 - 3.5) × (-0.1) = 0.90
```

**関連ファイル**: `src/analysis/extended_scorer.py` - `calculate_matchup_score()`

**工数**: 1日
**期待効果**: 「B1だが絶好調」の選手を適切に評価 → +1-2pt精度向上

| 2着専用スコアラー | 差し・まくり差し特化（AUC 0.6819） | 1着予測に依存 |

**改善案**:

#### P-3a. 3着専用スコアラーの新規作成

**考え方**: 1着・2着が決まったとして、誰が3着かを予測

```
3着候補の特徴:
- 展開次第で浮上する選手（差し・まくり差し展開で追走）
- 1着・2着の展開による影響を受ける
- 例: 3コースまくり → 4コースが追走して3着に絡みやすい
```

#### P-3b. 展開予測の導入

**1着の決まり手別に2着・3着を予測**:

| 1着決まり手 | 2着有利 | 3着有利 | 備考 |
|------------|---------|---------|------|
| 1コース逃げ | 2,3コース | 4コース | インコース有利維持 |
| 3コースまくり | 4コース | 5コース | 外追走 |
| 4コースまくり | 5コース | 6コース | 最外追走 |
| 2コース差し | 1コース | 3コース | イン残し |

**実装方針**:
1. 1着予測の決まり手確率を計算
2. 決まり手別に2着・3着の条件付き確率テーブルを作成
3. 階層的予測に展開予測を統合

**関連ファイル**:
- `src/analysis/hierarchical_predictor.py`
- `src/models/conditional_rank_models/` (新規作成)

**工数**: 3-5日

### P-4. 信頼度C,Dの精度向上（中穴・穴予想） 🟡

**現状の課題**:
- 信頼度C,Dは信頼度A,Bの「副産物」
- 中穴・穴の専用ロジックがない
- 非1コース予測時の精度が低い（24.8%）

**事実**:
- 信頼度D × 非1コース予測 = ROI 298.0%（最高収益源）
- 3コース予測 = ROI 351.1%
- ただし的中率は低い（精度向上の余地あり）

**改善案**:

| 項目 | 現状 | 改善案 |
|------|------|--------|
| 信頼度C,D判定 | A,Bの逆（スコア差小） | ✅ 維持（高オッズ狙いに有効） |
| 穴予測ロジック | 共通ロジック | 🔴 **新規追加**: 穴専用の評価軸 |
| 穴評価軸 | なし | 前付け傾向、展開荒れ指標、モーター絶好調 |

**穴専用評価軸（案）**:
1. **前付け傾向**: 前付け常習者がいる → 展開荒れやすい → 穴狙いに有利
2. **展開荒れ指標**: 1コースが弱い会場 × 強風 → 荒れやすい
3. **モーター絶好調**: 級別は低いがモーター2連対率80%以上 → 穴候補

**工数**: 2日
**期待効果**: 信頼度C,D的中率 +2-3pt
