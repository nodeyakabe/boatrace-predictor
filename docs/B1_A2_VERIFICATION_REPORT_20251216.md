## 1. B-1 会場フィルター検証

### 1.1 バックテスト結果

| 指標 | フィルターなし | フィルターあり | 差分 |
|------|--------------|--------------|------|
| 購入レース | 489件 | 489件 | - |
| 総賭け金 | 196,700円 | 163,000円 | -33,700円 |
| 総払戻 | 275,670円 | 308,210円 | +32,540円 |
| 収支 | +78,970円 | +145,210円 | +66,240円 |
| **ROI** | 140.1% | **189.1%** | **+48.9pt** |

### 1.2 統計的有意性検定

**Welchのt検定結果**:

| 指標 | 値 | 判定 |
|------|-----|------|
| サンプルサイズ | 489件 | OK |
| ベースライン平均ROI | 149.63% | - |
| フィルター適用平均ROI | 149.63% | - |
| t値 | **0.0000** | - |
| **p値** | **1.0000** | **NG (>= 0.05)** |
| 効果量 Cohen's d | **0.0000** | ごく小さい |

**95%信頼区間**:
- ベースライン: [49.20%, 250.06%]
- フィルター適用: [49.20%, 250.06%]
- **完全に重複** → 有意差なし

### 1.3 なぜp値が1.0になったか

**重要な発見**: t検定で使用した平均ROIが同一であった。

これは以下を意味する：
1. **フィルターは購入金額を変えるだけ**で、的中/外れの結果は変わらない
2. レース単位のROI（払戻/賭け金）は、倍率を変えても比率として同じ
3. したがって、**平均ROIに差が出ない**

つまり、B-1会場フィルターは：
- **総ROI（総払戻/総賭け金）では改善に見える**（Tier1会場の比重増加）
- **レース単位の平均ROIでは改善なし**（統計的に有意ではない）

### 1.4 過学習リスク評価

**リスクレベル: 高**

| リスク要因 | 詳細 |
|-----------|------|
| 年度間検証不能 | 2024年のbefore予測データが66件のみ |
| 統計的有意性なし | p値 = 1.0000 |
| サンプル少 | 489件（推奨: 500件以上） |
| 効果量ゼロ | Cohen's d = 0.0000 |

### 1.5 現行ROI 167%との比較

| 比較項目 | 値 | 判定 |
|---------|-----|------|
| 現行ROI | 167.0% | 基準 |
| B-1フィルター適用後ROI | 189.1% | OK |
| B-1フィルターなしROI | 140.1% | NG |

**注意**: 現行ROI 167%を上回っているように見えるが、統計的有意性がないため、**偶然の可能性が高い**。

| グループ | サンプル数 | 的中 | 賭け金 | 払戻 | ROI |

### 2.3 検出力分析

| 項目 | 値 |

**結論**: Treatment群のサンプルが不足しているため、中程度の効果を検出する検出力が不足。

## 4. 本日の教訓との整合性

### 4.1 教訓の適用

| 教訓 | 今回の適用 |
|------|-----------|
| 精度改善 ≠ ROI改善 | **ROI改善に見えても統計的有意でなければ採用しない** |
| データセットの一貫性 | 2024年データがないため一貫性検証不能 |
| 統計的有意性（p<0.05）必須 | B-1: p=1.0、A-2: p>0.05 → **全て不採用/保留** |
| 現行ROI 167%を下回らない | 統計的に保証できない |

### 4.2 今回の教訓

**新たな教訓**: 「バックテストでのROI改善」と「統計的に有意なROI改善」は異なる

- B-1はバックテストでROI +48.9pt改善に見えた
- しかし、t検定で有意差なし（p=1.0）
- これは**購入金額の再配分**であり、**予測精度の改善ではない**

## 5. 最終判定と推奨アクション

### 5.1 B-1 会場フィルター

**判定: 不採用**

**理由**:
1. 統計的有意性なし（p=1.0000、要件: p<0.05）
2. 過学習リスクが高い（2024年データで検証不能）
3. 効果量がゼロ（Cohen's d = 0.000）
4. 改善効果がノイズの範囲内である可能性

**推奨アクション**:
- 現行システムを維持
- 2024年のbefore予測データを追加生成してから再検証
- または、別のアプローチ（会場別モデル学習など）を検討

### 5.2 A-2 特徴量A/Bテスト

**判定: 判定保留**

**Treatment A（会場xコース）**:
- ROI +32.74pt（211.6% vs 140.3%）の傾向
- しかしp=0.78で有意差なし
- サンプル追加後に再検証

**Treatment B（天候強化）**:
- ROI -100.47pt（62.0% vs 140.3%）の傾向
- しかしp=0.29で有意差なし
- サンプル追加後に再検証

**推奨アクション**:
- 現状維持（既存の特徴量を変更しない）
- サンプルが蓄積したら再検証（目安: 各グループ200件以上）
