## 5. 注意事項

### 絶対に避けるべきこと

1. **複数プロセスで同時に同じ年度を処理しない**
   - UNIQUE制約エラーの原因
   - DBロックの競合

2. **全削除→再生成はしない**
   - 途中停止でデータ喪失のリスク
   - UPSERT方式を使う

3. **generate_advance_ultrafast.py は使わない**
   - hierarchical_predictorが無効になる
   - D/Eのみの分布になってしまう

### 使用すべきスクリプト

```bash
# 正しい（A-E分布になる）
python scripts/generate_advance_fast.py --year XXXX  # ただし要修正

# または RacePredictor を直接使う
from src.analysis.race_predictor import RacePredictor
predictor = RacePredictor()
predictions = predictor.predict_race(race_id, use_beforeinfo=False)
```
